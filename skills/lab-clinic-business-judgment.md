# ธุรกิจคลินิกแล็บ MT — เลือกโมเดล + กันคู่แข่ง

สำหรับ MT ที่คิดเปิด/บริหารคลินิกเทคนิคการแพทย์เอง — เน้น **"เลือกโมเดลไหนเมื่อไหร่ + พลาดตรงไหนถึงเจ๊ง"** ไม่ใช่ตำราตลาด

> **กฎ #1:** moat ของคลินิกแล็บ **ไม่ใช่เครื่องมือ** (ใครก็ซื้อได้) — แต่คือ **ความชอบธรรมวิชาชีพ (จดทะเบียน + ดำเนินโดย ทนพ. + รับรองสภา) + "มีคนอธิบายผล/ดูแลต่อเนื่อง" + เชื่อมระบบรัฐได้**. แข่งด้วยราคาอย่างเดียว = มักแพ้
> **กับดัก #1:** เก่งแล็บ แต่อ่อน business/brand/marketing/law → นั่นคือจุดแพ้-ชนะจริง ไม่ใช่คุณภาพผลตรวจ (ส่วนใหญ่แล็บได้มาตรฐานพอกัน)
> โยง: `mt-career-judgment` (เส้นทางเป็นเจ้าของ) · `ivd-sales-judgment` (ฝั่งขายของให้คลินิก) · `finance-judgment` (unit economics + CFO) · `mt-law-ethics-judgment` (ขอบเขต+จดทะเบียน) · `digital-judgment` (PDPA ข้อมูลคนไข้)

## ใช้เมื่อ
- คิดเปิดคลินิกแล็บ / ขยายสาขา / เลือกโมเดลธุรกิจ
- ตัดสินว่าจะเข้าระบบรายได้รัฐ (เช่น Lab Anywhere/สปสช.) ไหม
- ประเมินว่าคลินิกจะรอดภัยคุกคาม (รพ.เปิดศูนย์เอง, แล็บใหญ่, POCT, self-test, price war) ยังไง
- (สาย sales) อยากอ่านใจ buyer = เจ้าของคลินิกแล็บ ก่อนเข้าไปขาย

## วิธีใช้
เล่าสถานการณ์ (ทุน, ทำเล, ลูกค้าเป้า, มี รพ.คู่ไหม) → จะได้ fork ที่ต้องตัดสิน + กับดักที่ต้องเลี่ยง + จุดที่ต้องไปหาตัวเลขจริงก่อน

## วิธีตัดสินใจ (AI: ทำตามนี้)

### Fork 1 — เลือกโมเดล: Premium-Longevity vs Volume-รัฐ vs Hybrid
ถามก่อน: **มี brand/demand แล้วหรือยัง? ทุนหนาแค่ไหน? ทำเลใกล้ รพ.คู่ไหม?**

| | Premium / Longevity | Volume / รัฐ (เช่น Lab Anywhere) |
|---|---|---|
| ลูกค้า | รายได้สูง, องค์กร, ต่างชาติ | mass, สิทธิรัฐ, ใกล้บ้าน |
| รายได้ | package แพง + **subscription/recurring** | fee-per-test **ต่ำ → ต้อง volume** |
| margin | หนา | บาง |
| moat | brand + แปลผล + experience | จดทะเบียน + LIS-HIS + อยู่ในระบบรัฐ |
| เสี่ยง | ต้องสร้าง demand เอง, พึ่ง branding | พึ่งนโยบาย, margin บาง, ผูก รพ.คู่ |

- **verdict:** บ่อยครั้ง **hybrid คุ้มสุด (ขึ้นกับบริบท)** — มักเปิดด้วย volume/รัฐ ก่อน (cashflow + ความชอบธรรม + คนเดินผ่าน) → **upsell premium ทับ** เพื่อ margin. อย่าเริ่มด้วย premium ล้วนถ้ายังไม่มี brand/demand จริง (จะไม่มีลูกค้า)
- **recurring > one-shot:** โมเดลที่อยู่รอด = ขาย "การติดตามต่อเนื่อง" (ตรวจซ้ำตามรอบ + coaching) ไม่ใช่ "ตรวจครั้งเดียวจบ"
- **เลือก accreditation ตาม "ตลาด" ไม่ใช่แค่ compliance:** ISO 15189 = มาตรฐานสากล ที่ตลาด medical-tourism/พาร์ตเนอร์ต่างชาติรับรู้เป็นสัญญาณคุณภาพ → positioning ฝั่ง premium/international · LA (สภาฯ) = ถูกกว่า เน้นในประเทศ/งานรัฐ — ทั้งคู่ "ดี" ต่างที่ audience + งบ → ใช้ป้ายรับรองเป็นเครื่อง *ขับ growth/ความน่าเชื่อ* ไม่ใช่แค่ผ่าน audit (มุม QMS เทคนิค → `lab-management-judgment`)

### Fork 2 — moat: กันคู่แข่งด้วยอะไร (รพ.เปิดศูนย์เอง / แล็บใหญ่ / POCT / self-test / price war)
- **moat ที่จริง 3 ชั้น:** (1) **ความชอบธรรมวิชาชีพ** — จดทะเบียนสถานพยาบาล + ดำเนินโดย ทนพ. + รับรองสภา = กำแพงกันทุนนอก/คนไม่ใช่ MT (2) **"มีคนอธิบายผล + ดูแลต่อเนื่อง"** = จุดที่ชนะ self-test/POCT (มนุษย์ + วิชาชีพ ที่กล่องตรวจให้ไม่ได้) (3) **LIS-HIS integration** = ตั๋วเข้าระบบรัฐ/รับ outsource จาก รพ.
- **กับดัก:** แข่งราคาอย่างเดียว = race to the bottom (มีคนถูกกว่าเสมอ) · เครื่องทันสมัยอย่างเดียวไม่ใช่ moat (ทุนใหญ่ซื้อทับได้)
- **รายได้ที่มองข้าม:** รับ **outsource งานแล็บจาก รพ./คลินิกอื่น (B2B reference lab)** = volume + stable มากกว่า walk-in อย่างเดียว

### Fork 3 — ปิด business-gap ที่ MT ส่วนใหญ่ขาด (จุดแพ้-ชนะจริง)
MT เก่ง bench แต่มัก**อ่อน: business model · branding · digital marketing · กฎหมาย · การเปลี่ยนผลตรวจเป็นคุณค่า**
- **verdict:** อย่าทุ่มกับ "ซื้อเครื่องดีกว่า" — ทุ่มปิด gap นี้ก่อน (เรียน/จ้าง/หาหุ้นส่วนสาย business+marketing+law)
- **ใช้ AI ปิด gap:** automate report/แปลผลให้คนเข้าใจ/การตลาด = "AI ไม่แทน MT แต่แทนคนที่ไม่ใช้ AI". คนที่มี data/AI skill = ได้เปรียบเชิงโครงสร้างตรงนี้
- เกณฑ์คลินิกที่รอดระยะยาว = **น่าเชื่อถือสุด + อธิบายผลดีสุด + เข้าถึงง่ายสุด + ใช้ข้อมูลเป็นสุด** ไม่ใช่ "เครื่องใหม่สุด"

### Fork 4 — เข้าระบบรายได้รัฐ (Lab Anywhere/สปสช.) ไหม
- **คืออะไร (ระดับตัดสินใจ):** ท่อรายได้รัฐที่ให้คลินิก MT เจาะ/ตรวจแล็บผู้ป่วยเรื้อรัง (OP) + งานป้องกันโรค (PP) เบิกตรงจาก สปสช. ไม่ผ่าน รพ. จ่ายเป็นรอบ *(เงื่อนไข/รายการ/อัตราเปลี่ยนตามพื้นที่+เวลา — เช็คแหล่งทางการล่าสุด)*
- **เข้าเมื่อ:** อยู่ใกล้ รพ.คู่ที่เชื่อม **LIS-HIS** ได้ · ทำ **volume** ได้จริง · ผ่านมาตรฐาน (เช่น MOPH Standard) · พร้อม setup (ระบบพิสูจน์ตัวตน/ขึ้นทะเบียน/เบิกจ่าย)
- **ถ้าเข้า — ให้ รพ. ยืนยันส่งเคสก่อนจ่ายค่าเชื่อมระบบ (landmine):** การเชื่อม HOSxP/BMS = หลักแสน. กับดักที่เจอบ่อย — รพ.บังคับ "ต้องเชื่อมระบบก่อนถึงให้ทำ" แต่ไม่ยอมรับปากจำนวนเคส → ลงทุนแล้วเขาไม่ส่ง = เสี่ยงเงินจม. **แนวทางลดความเสี่ยง (จากเคสเล่า):** คุย รพ. ก่อนว่า "ถ้าเปิด จะส่งกี่เคส/วัน + เงื่อนไขอะไร" ทำ MOU/หนังสือแจ้งเจตนา/ประเมิน volume ก่อนลงทุน · **โดยทั่วไป สปสช. ไม่การันตี volume ให้คลินิก และไม่ได้สั่ง รพ. ให้ส่งเคสโดยตรง** (อยู่ที่ ผอ./รพ. สมัครใจ — ยึดสัญญา/ประกาศพื้นที่ล่าสุด) — ผู้บริหารที่มองคลินิกเป็น "คู่แข่ง" ไม่ใช่ "พาร์ตเนอร์ปฐมภูมิ" มักทำให้เคสไม่ไหล
- **เช็ค buy-in 4 ฝั่งก่อนเข้า:** (1) ตัวเรา—เป็นโอกาสจริงไหม (2) ผู้ป่วยในพื้นที่—พร้อมมาคลินิกแทนแถว รพ.ไหม (3) บุคลากร รพ. (หัวหน้าแล็บ/พยาบาล OPD/IT/เวชระเบียน) (4) ผู้บริหาร/ผอ. — ครบ 4 ฝั่งมองบวก = ปัจจัยที่ช่วยให้รอด
- **รายการนอกชุดเบิก = จุดพลาดเรื่องการเงิน/กฎได้ง่าย:** ตัวที่อยู่นอกชุด (เช่น PT/INR คนไข้วาฟาริน) มักเบิกไม่ได้ และหลายเงื่อนไข สปสช. ห้ามเก็บเงินคนไข้ในสิทธิ์ → **ก่อนเลือกวิธีจัดการ (เช่น แบ่งหลอดส่ง รพ.ตรวจ / คลินิกตรวจเฉพาะตัวที่เบิกได้) ต้องเช็คประกาศ สปสช. + สัญญา รพ. + consent ให้ชัด · ห้ามทำเพื่อเลี่ยงกฎ/เบิกซ้ำ** · เก็บหลักฐาน (เวชระเบียน/ใบสั่งตรวจ/ผล) เผื่อ audit ย้อนหลัง (เคสเล่า ~10 ปี — เช็คระยะที่กำหนดจริง)
- **กับดัก:** margin **มักบาง** (fee/test ต่ำ — ตรวจอัตราล่าสุด) → ไม่มี volume = ขาดทุน · พึ่งนโยบายรัฐ = เปลี่ยน/ยกเลิกได้ · setup cost (gateway/ระบบ/มาตรฐาน) สูง · compliance บังคับ (เช่น **รายงานค่าวิกฤตทันที + บันทึกทุกครั้ง**)
- **อย่าเข้าใจผิด:** นี่คือ **cashflow ฐาน + ความชอบธรรม** ไม่ใช่ตัวทำกำไรหลัก — ใช้คู่กับ premium ที่ margin หนา (Fork 1)

### Fork 5 — (สาย sales) อ่านใจ buyer = เจ้าของคลินิกแล็บ
- **pain เขา:** โดนกดราคา · รพ.เปิดศูนย์แข่ง · POCT/self-test แย่งงาน · ขาด business skill
- **เขาอยากซื้อ:** เครื่องที่ **ลด cost/คน** · panel มูลค่าสูง (longevity/preventive: ApoB, hs-CRP, sd-LDL, insulin, HbA1c, Vit D ฯลฯ) · QC/calibration/service contract · **LIS/middleware/gateway/Kiosk** · AI ช่วย report/marketing
- **verdict:** อย่าเปิดด้วย "เครื่องเราแม่นกว่า" — เปิดด้วย **pain บริหารของเขา + value/test + ลด cost** (ดู `ivd-sales-judgment` Fork เปิดด้วย pain)

### Fork 6 — ก่อนลงเงินจริง: หา data ที่ vision deck ไม่มี
สไลด์/เสวนาธุรกิจคลินิกมักเป็น **vision + workflow ไม่มี financial model** → ต้องหาเองก่อนตัดสิน:
- **market size จริง** (ไม่ใช่ "ตลาดโต rapidly" ที่ไม่มี source)
- **unit economics:** ไม่ใช่แค่ "ค่า reagent ต่อ test" — ต้องสร้าง **cost stack เต็ม (fixed + variable)** ก่อนคิด break-even/ตั้งราคา → ดู **Fork 7**
- **กฎหมาย/ภาระผูกพัน:** จดทะเบียนสถานพยาบาล, ขอบเขตวิชาชีพ, เงื่อนไขจ้างงาน/บอนด์ (ถ้ามี)
- **setup cost:** มาตรฐาน (MOPH/ISO 15189), LIS-HIS, ระบบเบิกรัฐ
- **กับดัก:** เชื่อ vision deck เป็น business plan = เจ๊ง (ไม่มี unit economics). ดู CFO/break-even จริงก่อน (โยง `finance-judgment`)

### Fork 7 — สร้าง "cost stack" เต็มก่อน quote ราคา/ตัดสินว่ารอด (กับดัก: นับแต่ต้นทุนตรง)
ก่อนบอกราคาต่อ test หรือสรุปว่า "คลินิก/แล็บนี้รอด" — **สร้างต้นทุนทั้งกอง ไม่ใช่แค่ค่าน้ำยา**
- **กับดักคลาสสิก (เทียบร้านอาหารดังที่เจ๊งเพราะคำนวณต้นทุนผิด):** แล็บมักนับแต่ **ต้นทุนตรง/ผันแปร (variable)** = น้ำยา + วัสดุสิ้นเปลืองต่อ test แล้วบวกราคานิดเดียว → **ลืมต้นทุนแฝง/คงที่ (fixed) ที่รวมกันอาจ "เท่า" ต้นทุนตรง** → ขายต่ำกว่าทุนจริงทั้งที่กำไรบัญชี "ดูบวก" (เพราะไม่เคยปันส่วน fixed ลงต่อ test)
- **4 ก้อนต้นทุนแฝงที่มักลืม:**
  1. **คน (fully-loaded)** — ไม่ใช่เงินเดือนฐาน แต่ + สวัสดิการ/ประกันสังคม/OT + **ต้นทุนวันลา/คนแทนตอนขาด** (ต้องมีคนคุมเครื่องเสมอ)
  2. **สถานที่/utilities** — **ค่าเช่า** + น้ำ + ไฟ + **เน็ต** (LIS/เบิกรัฐ/ผลออนไลน์ ต้องมี)
  3. **operation** — สัญญา service/ซ่อมเครื่อง (PM/calibration) + **คนนอกสายแล็บ** (แม่บ้าน · ช่างแอร์/ช่างที่มาราวด์)
  4. **ค่าเสื่อม (depreciation)** — เครื่อง/ทุนที่ซื้อ ต้องเฉลี่ยลงต่อปี/ต่อ test ไม่ใช่ "จ่ายทีเดียวจบ = ฟรีตลอด"
- **สูตรตัดสิน:** `true unit cost ≈ variable/test + (fixed รวมต่อเดือน ÷ จำนวน test/เดือน)` → **เช็ค ราคาขาย ≥ true unit cost เสมอ แม้เป็น non-profit/แล็บรัฐ** (ไม่งั้น "ยิ่งตรวจยิ่งขาดทุน" — volume ต่ำยิ่งเจ็บ เพราะ fixed หารด้วยเลขน้อย)
- **กับดักภาครัฐ (โยง "ทำไมค่าตอบแทน MT ต่ำ"):** แล็บรัฐมักไม่คิด fixed เลย ("รัฐจ่ายค่าที่/เงินเดือน/เครื่องให้อยู่แล้ว") → ตั้งราคาบนค่าน้ำยาอย่างเดียว → กดราคาอ้างอิงทั้งตลาดให้ต่ำผิดจริง = เหตุผลเชิงโครงสร้างข้อหนึ่งที่ **มูลค่างาน MT ถูกตีต่ำ + ค่าจ้างไม่ขึ้น** (ต้นทุนคนถูกซ่อน ไม่เคยโผล่ในราคา)
- *(ตัวเลข/โครงสร้าง/วิธีปันส่วนต่างกันตามหน่วย ขนาด และระบบบัญชี — verify กับบัญชีจริงของหน่วยตัวเองก่อนใช้)*

### Fork 8 — พลวัตราคาพื้น (price floor): ทำไมตั้งราคาร่วมกันไม่รอด + ใครกดราคาจริง
- **ตกลงราคาขั้นต่ำกันในกลุ่ม (price fix/cartel) มักพัง:** ต่อให้เจ้าใหญ่จับมือตั้ง floor — **รายเล็ก "รายที่ 5" ที่ต้นทุนต่ำ/อยากได้งานจะตัดราคาเสมอ** → floor แตก (ธรรมชาติตลาดผู้เล่นเยอะ + กันสมคบราคาไม่ได้จริง; การฮั้วราคายังผิดกฎหมายแข่งขันทางการค้าด้วย)
- **ตัวกดราคาที่ใหญ่สุด = การจัดซื้อภาครัฐ:** ราคากลาง/ประมูล/อัตราเบิกรัฐที่ตั้งบนต้นทุนตรง (ดู Fork 7) = ตัวเซ็ต reference ให้ทั้งตลาดต่ำ → เอกชนถูกลากตาม
- **verdict:** อย่าวางแผนรอดบน "หวังตลาดจะไม่ตัดราคา" — วางบน **cost ต่ำจริง (Fork 7) + moat ที่ไม่ใช่ราคา (Fork 2)** เพราะราคาจะถูกกดลงเสมอ

## กับดัก (Anti-patterns)
- **เริ่ม premium ล้วนทั้งที่ยังไม่มี brand/demand** → ไม่มีลูกค้า เงินจม
- **แข่งด้วยราคาอย่างเดียว** → race to the bottom, ทุนใหญ่บีบตาย
- **เชื่อ vision deck เป็น business plan** → ไม่มี unit economics/break-even = เจ๊งเงียบ
- **นับแต่ต้นทุนตรง (น้ำยา/วัสดุ) แล้วตั้งราคา** → ลืม fixed/hidden ที่อาจ "เท่า" ต้นทุนตรง → ขายต่ำกว่าทุนจริงทั้งที่กำไรบัญชีดูบวก (ดู Fork 7)
- **แล็บรัฐ/non-profit ตั้งราคาบนค่าน้ำยาอย่างเดียว ("รัฐจ่าย fixed ให้แล้ว")** → กดราคาทั้งตลาด + เป็นเหตุผลเชิงโครงสร้างที่ค่าจ้าง MT ต่ำ
- **หวังรอดด้วยการตกลงราคาขั้นต่ำกับคู่แข่ง** → รายเล็กตัดราคาเสมอ floor แตก (และผิดกฎแข่งขันฯ); ตัวกดราคาจริงคือการจัดซื้อรัฐ (ดู Fork 8)
- **มองข้าม LIS-HIS integration** → เข้าระบบรัฐ/รับ outsource ไม่ได้ = ตัดท่อรายได้ volume ทิ้ง
- **เก่งแล็บอย่างเดียว ละเลย business/brand/law** → จุดแพ้จริงไม่ใช่คุณภาพผล
- **พึ่ง Lab Anywhere/รัฐ เป็นกำไรหลัก** → margin บางเกิน, นโยบายเปลี่ยนได้ = เปราะ
- **คิดว่า moat = เครื่องมือ** → ทุนใหญ่ซื้อทับได้; moat จริง = วิชาชีพ + จดทะเบียน + ความสัมพันธ์ + ระบบ
- **ดัน "health coaching / longevity" จนเลยขอบเขต** — แปลผล biomarker + แนะนำปรับพฤติกรรม + ส่งต่อ = ทำได้ และเป็น value จริงของคลินิก แต่ **MT ไม่วินิจฉัย/ไม่สั่งยา** · ค่าผิดปกติ/สงสัยโรค = refer แพทย์ ไม่ใช่ coach แทนการรักษา (โยง `mt-law-ethics-judgment`)
- **เปิดหัวชนหัวกับคลินิกเดิมที่รุ่งในพื้นที่เดียวกัน** → ในฐานะ newcomer สายป่านสั้นกว่า มักแพ้ price war/ขาดทุนก่อน · ทางรอด = หา **ตลาด/อำเภอใหม่** (หลายอำเภอยังขาด MT) ไม่ใช่แย่งเค้กเดิมด้วยการตัดราคา
- **เปิดเพราะ "บ้านอยู่อำเภอนี้"** → ถ้าพฤติกรรมลูกค้าตรงนั้นไม่ตรง เสี่ยงขาดทุนสูง · เลือกทำเลที่ลูกค้า/behavior fit (เช่น ใกล้ รพ. เพื่อรับเคส LAAB) แม้ไกลบ้าน — follow ลูกค้า ไม่ใช่ความสะดวกตัวเอง *(บทเรียนผู้ประกอบการ ไม่ใช่กฎตายตัว)*
