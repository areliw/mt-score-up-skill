## 🔴 Tier 1 — Confirmed clinical errors (verified-real, fix now)

**1. [CRITICAL] `bloodbank-judgment.md:75` — Bombay/anti-H under "prewarm 37°C" crossmatch row**
Prewarming defeats only **cold** autoantibodies; **anti-H in Bombay reacts at 37°C** and causes fatal acute intravascular hemolysis. Self-contradicts the file's own lines 50/147 (Bombay = Bombay-only blood; anti-H "แรง 37°C").
→ **Fix:** remove Bombay/anti-H from the prewarm row (keep prewarm for cold autoAb / benign anti-HI only); route Bombay → "Bombay-only unit + AHG XM + rare registry / ref lab" per line 50.

**2. [HIGH] `bloodbank-judgment.md:57` — antibody rule-out condition inverted**
Says cross out where "cell ลบ แต่ reaction บวก" (Ag−/react+). Backwards — you rule **out** an antibody when an **Ag-POSITIVE** cell reacts **NEGATIVE** (Ag+/react−). A student would mis-ID antibodies.
→ **Fix:** "ขีดฆ่า antibody เมื่อ cell ที่ Ag-POSITIVE ให้ reaction ลบ (Ag+/react−), rule-out ด้วย homozygous cell."

**3. [HIGH] `chemistry-interpretation-judgment.md` Fork 2 — Jaffe interference → GFR direction backwards**
Lists positive chromogens (glucose/protein/vitC/ASA/ceph) ↑Cr but concludes "→ overestimate GFR." ↑Cr (denominator) → **UNDERestimate** GFR. Only bilirubin (↓Cr) overestimates.
→ **Fix:** "positive chromogens ↑Cr → UNDERestimate GFR (overstate injury); bilirubin ↓Cr → overestimate GFR → use enzymatic Cr."

**4. [HIGH] `clinical-correlation-judgment.md` (lines 42, 77, 89) — "low albumin + normal AST/ALT → not liver = glomerular"**
Wrongly excludes liver: 37–48% of (compensated) cirrhotics have normal transaminases; albumin is a hepatic synthetic product. Error is even inside the anti-anchoring guardrail section.
→ **Fix:** low albumin = hepatic (cirrhosis/synthetic failure) OR renal loss OR malnutrition/inflammation; differentiate with PT/INR, GGT/ALP, urinalysis (RBC cast = glomerular), not transaminases alone.
