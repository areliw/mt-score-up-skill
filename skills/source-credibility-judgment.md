# ประเมินความน่าเชื่อของแหล่ง/ผู้เขียน

ตัดสินว่า "แหล่ง/คนที่พูดอันนี้" เชื่อได้แค่ไหน ก่อนจะเอาไปอ้าง/ตัดสินใจ — ดูที่ **สัญญาณความน่าเชื่อ** (ใครพูด · ผ่านการตรวจระดับไหน · มีผลประโยชน์ทับซ้อนไหม) ไม่ใช่ดูแค่ว่า "ฟังดูดี".

> **กฎข้อ 1:** ก่อนเชื่อ ถาม 3 ข้อ — **(1) ใครพูด & มี track record ในเรื่องนี้ไหม (2) ผ่านการตรวจอิสระระดับไหน (peer-review จริง / แค่ขึ้นเว็บ) (3) คนพูดได้/เสียอะไรถ้าเราเชื่อ (conflict of interest)** → น้ำหนักความเชื่อ = ฟังก์ชันของ 3 ข้อนี้ ไม่ใช่ความลื่นของภาษา.
> **กับดักข้อ 1:** เห็น "มีงานวิจัยรองรับ / ตีพิมพ์แล้ว" แล้วเชื่อทันที — **ตีพิมพ์ ≠ น่าเชื่อ**. predatory journal รับลงทุกอย่างที่จ่ายเงิน, vendor whitepaper คือโฆษณาที่แต่งตัวเป็นงานวิจัย, ตัวแทนบริษัทอ้าง "ผลวิจัย" ที่ไม่เคยให้ดูตัวเต็ม. **ต้องเช็กว่าใครตรวจ + ใครจ่าย ก่อนนับว่าเป็นหลักฐาน.**

## ใช้เมื่อ
- เจอ claim/ตัวเลข/คำแนะนำ แล้วต้องตัดสินว่า "เชื่อแล้วเอาไปใช้ได้เลยไหม"
- ตัวแทนบริษัท/vendor อ้างว่า "มีงานวิจัย/ข้อมูลรองรับ" (น้ำยา เครื่องมือ kit)
- จะ cite แหล่งในงาน R2R/thesis/journal club — เลือกว่าอันไหนน้ำหนักพอ
- AI สรุปข้อมูล/ให้ลิงก์มา แล้วต้องเช็กว่าแหล่งที่มันอ้างเชื่อได้จริงไหม
- เจอข่าว/โพสต์/บล็อกสุขภาพ-แล็บ แล้วไม่แน่ใจว่าเป็นหลักฐานหรือความเห็น

## วิธีใช้
วาง skill นี้ + แปะแหล่ง/claim/ลิงก์/ชื่อผู้เขียน-วารสาร (หรือเล่าว่าใครพูดอะไรในบริบทไหน) → AI ช่วยจัดระดับน้ำหนักความเชื่อ + ชี้ red flag + บอกว่าต้องไปยืนยันต่อตรงไหนก่อนใช้จริง

## วิธีตัดสินใจ (AI: ทำตามนี้) — forks

### Fork 1 — จัดชั้น peer-review tier (ตรวจอิสระระดับไหน)
⚠️ **อย่าตัดสินความน่าเชื่อจาก "ชนิดแหล่ง" ล้วน — match design ↔ คำถามก่อน แล้วค่อยดู method/directness/precision/ปี/CoI** (RCT ไม่เหมาะกับคำถาม diagnostic/prevalence/prognosis; IFU เป็น authority ของ "วิธีใช้ที่อนุมัติ"). ตารางนี้ = default ของ "ใครตรวจก่อนเผยแพร่" ไม่ใช่ชั้นสูงชนะทุกคำถาม:

| ชั้น | ตัวอย่าง | น้ำหนัก |
|---|---|---|
| สูง | systematic review/meta-analysis, guideline (CLSI/WHO/สมาคมวิชาชีพ), RCT ในวารสารมี peer-review จริง | เชื่อเป็นฐานได้ ยังต้องดู Fork 3 |
| กลาง | research article ในวารสารมาตรฐาน, IFU/ฉลากที่ผ่าน regulator | หลักฐานใช้ได้ แต่ดู scope/CoI |
| ต่ำ | preprint (ยังไม่ผ่าน review), abstract งานประชุม, บทความ review เชิงเล่า | ใช้ชี้ทิศ ห้ามใช้เป็นข้อสรุปเดี่ยว |
| ไม่นับเป็นหลักฐาน | vendor whitepaper, blog, โพสต์ social, ข่าว PR, AI summary | = ความเห็น/โฆษณา ต้องไล่กลับไปต้นทาง |

### Fork 2 — เช็ก track record ผู้เขียน/แหล่ง
- คนพูด/เขียน มี **ประสบการณ์ตรงในเรื่องนี้** ไหม (เชี่ยวชาญด้านที่ตรง ≠ ดังในด้านอื่น)
- เคยมีประวัติงานถูก retract / ถูกจับโกหก / ขายของอย่างเดียวไหม
- ⚠️ **ชื่อเสียง/ตำแหน่ง/ปริญญา ≠ ถูกอัตโนมัติ** — ดูเนื้อ + หลักฐานที่ให้มา ไม่ใช่ดูแค่ "ดร."

### Fork 3 — Conflict of interest (ใครได้/เสียถ้าเราเชื่อ)
- ⚠️ **ถ้าคนให้ข้อมูล = คนได้เงินจากการที่เราเชื่อ → ปรับน้ำหนักลงทันที** (ตัวแทนขายน้ำยา/เครื่อง อ้างว่าเครื่องตัวเองดีกว่า = ต้องหาแหล่งอิสระยืนยัน)
- ดู funding/sponsor ท้ายเปเปอร์ — งานที่บริษัทจ่ายแล้วผลออกมาเข้าข้างบริษัท = ระวัง
- vendor whitepaper / case study บนเว็บบริษัท = การตลาด ไม่ใช่หลักฐานกลาง
- ⚠️ **ดูปีตีพิมพ์ด้วย** — แหล่ง tier สูงแต่เก่าจน guideline ปัจจุบันเปลี่ยนไปแล้ว = outdated, เช็กว่ามีฉบับ/แนวทางใหม่กว่าทับหรือยังก่อนใช้

### Fork 4 — Primary vs Secondary (ไล่กลับไปต้นทาง)
- **Primary = งานต้นฉบับ** (ทดลอง/เก็บข้อมูลเอง) · **Secondary = พูดต่อ** (review, ข่าว, สรุป, AI)
- ⚠️ เจอ "งานวิจัยบอกว่า..." → **ไล่กลับไปอ่าน primary** ก่อนเชื่อ; คนกลางบิด/ตัดบริบทบ่อย
- AI สรุป = secondary ที่อาจ hallucinate ต้นทาง → เช็กว่าลิงก์/อ้างอิงมีจริง (ดู `anti-hallucination`)

### Fork 5 — VERDICT จับ predatory / fake-credibility
ถามชุดนี้ ถ้าเข้าหลายข้อ = **ธงแดง อย่านับเป็นหลักฐาน**:
- วารสารเก็บค่าตีพิมพ์แต่ไม่มี peer-review จริง / สแปมชวนลง / ชื่อเลียนวารสารดัง
- อ้าง "ผลวิจัย" แต่ **ไม่เคยให้ดูตัวเต็ม / ไม่มี method / ไม่มีเลขจริง**
- การันตีผล 100% / "พิสูจน์แล้ว" แบบไม่มีข้อจำกัด
- ตัวเลขสวยเกินจริง + ไม่มี comparator / ไม่บอก sample size
- เคย **ถูก retract** ไหม — เช็ก Retraction Watch / PubMed retraction notice ก่อนอ้าง (งานถูกถอนแล้วยังถูก cite ต่อเรื่อยๆ = ธงแดง)
→ ถ้าธงแดง: ใช้ `critical-appraisal-judgment` แกะเนื้องานต่อ หรือทิ้งแล้วหาแหล่ง tier สูงกว่า

### Fork 6 — สองชั้นนี้แยกให้ขาด (อย่าสับกับ critical-appraisal)
- **อันนี้ (source credibility)** = ประเมิน **"ความน่าเชื่อของแหล่ง/คนพูด"** — ใครพูด ตรวจระดับไหน ได้เสียอะไร (ใช้ "ก่อน" จะลงแรงอ่าน)
- **`critical-appraisal-judgment`** = ประเมิน **"คุณภาพเนื้องาน 1 ชิ้น"** — method แน่นไหม sens/spec/PPV เชื่อได้ไหม bias ตรงไหน (ใช้ "หลัง" รับว่าแหล่งน่าเชื่อพอจะอ่านลึก)
- ลำดับใช้จริง: source-credibility ใช้ **จัดลำดับความสำคัญ** (ไม่ใช่ตัดทิ้งเพราะ tier ต่ำ — ประเมิน method ต่อ เว้นแต่ปลอม/ถูก retract/ตรวจสอบไม่ได้) → critical-appraisal เนื้อ → `deep-research` หาข้อมูลเพิ่ม

## กับดัก (Anti-patterns)
- **"ตีพิมพ์แล้ว = เชื่อได้"** — predatory journal รับลงทุกอย่างที่จ่ายเงิน; เช็ก peer-review tier ก่อน
- **vendor whitepaper / ตัวแทนอ้างวิจัยแต่ไม่ให้ดูตัวเต็ม = หลักฐานกลาง** — no full text = ไม่นับ; หา primary/แหล่งอิสระ
- **ดูตำแหน่ง/ปริญญา/ความดัง แล้วเชื่อ** — authority ≠ หลักฐาน; ดูเนื้อ + CoI
- **ไม่ไล่กลับ primary** — เชื่อ "ข่าว/สรุป/AI พูดต่อ" ทั้งที่ต้นทางอาจถูกบิด (AI summary เช็กแหล่งมีจริงไหม — ดู `anti-hallucination`)
- **เอาความลื่น/ความยาว/กราฟสวย เป็นเครื่องวัดความน่าเชื่อ** — รูปแบบ ≠ ความจริง

## ช่องสำหรับผู้เชี่ยวชาญเติม
> เติมเคสจริงในสายงานคุณ เช่น:
> - *"(MT) ตอน vendor มาเสนอน้ำยา/เครื่อง ผมเช็กความน่าเชื่อของ data ที่เขาอ้างด้วยการ..."*
> - *"วารสาร/แหล่งที่ผมเจอว่าเป็น predatory คือ... สังเกตจาก..."*
> - *"เคสที่ผมเกือบเชื่อ claim ผิดเพราะดูแค่ 'มีงานวิจัย' คือ..."*
