# คุมงบ token/บริบทของ AI

AI จำได้แค่ "หน้าต่างความจำ" จำกัด — ใส่เกิน คุณภาพตก (อาจลืมบางส่วน/มั่ว/ช้า — ⚠️ *ระบบต่างกัน*: บางตัวตัดต้นแชต บางตัวสรุป/ปฏิเสธ/เก็บไม่เท่ากัน; อาการพวกนี้เป็น **สัญญาณ** ไม่ใช่ตัวชี้ขาดกลไก); สกิลนี้สอนว่าเมื่อไหร่ควรแตกงาน สรุปย่อ หรือเริ่มแชตใหม่ ไม่ใช่ท่องตัวเลข token เป๊ะ

> **กฎข้อ 1:** ใส่เข้า context เท่าที่งานนี้ต้องใช้จริง — ไม่ใช่ทุกอย่างที่มี. ก่อนแปะไฟล์/ประวัติยาว ถามตัวเองว่า "AI ต้องเห็นทั้งหมดนี้เพื่อตอบ *คำถามนี้* จริงไหม?" ถ้าไม่ → ตัด/สรุปก่อนใส่.
> **กับดักข้อ 1:** ยิ่งแชตยาว ≠ AI ยิ่งฉลาด. พอบริบทล้น AI จะ **ลืมต้นแชตเงียบๆ** (ไม่เตือน) แล้วตอบมั่นใจเหมือนเดิม — คุณจับไม่ได้จนผลผิด. แชตเดียวยาวๆ เพื่อให้ "มันจำทุกอย่าง" มักได้ผลแย่กว่าแตกเป็นแชตสั้นที่โฟกัส.

## ใช้เมื่อ
- แชตยาวจน AI เริ่มลืมต้นแชต / ตอบวนซ้ำ / ขัดกับที่ตกลงไว้ก่อนหน้า / ช้าลง
- จะอัปโหลดไฟล์ใหญ่ (PDF คู่มือ, statement, ชุดข้อมูล) ให้ AI ช่วยอ่าน
- งานหลายสเต็ป (ร่าง WI → ตรวจ → แก้ → สรุป) ในแชตเดียว
- อยากให้ AI ตอบ "นิ่ง" คุณภาพใกล้กันทุกครั้ง ไม่แกว่งตามความยาวแชต

## วิธีใช้
วาง skill นี้ตอนเริ่มงานยาว/ไฟล์ใหญ่/หลายสเต็ป → ใช้ตารางสัญญาณเตือนข้างล่างจับว่าบริบทเริ่มล้น แล้วเลือกท่าแก้ (แตกงาน / สรุปย่อ / เริ่มแชตใหม่) ตาม VERDICT; ไม่ต้องนับ token จริง ดูพฤติกรรม AI เป็นหลัก

## สัญญาณว่าบริบทล้น (เห็นอันไหน = ถึงเวลาแก้)

| สัญญาณที่เห็น | แปลว่า | ท่าแก้ |
|---|---|---|
| AI ลืมสิ่งที่บอกไว้ต้นแชต / ถามซ้ำของที่ตอบไปแล้ว | หน้าต่างความจำเลื่อนพ้นต้นแชต | สรุปประเด็นที่ล็อกแล้วเป็น bullet → เริ่มแชตใหม่ |
| ตอบวนซ้ำ / ย้อนไปจุดที่แก้ไปแล้ว | บริบทปนกันจนจับทิศไม่ได้ | เริ่มแชตใหม่ + แปะเฉพาะสรุป + ไฟล์ที่ยังต้องใช้ |
| ช้าลงชัด / ตอบขาดๆ หายๆ | ใกล้เพดาน input/output | แตกงานเป็นสเต็ปย่อย ทำทีละอัน |
| ขัดกับข้อตกลงก่อนหน้าแบบมั่นใจ | มันมองไม่เห็นข้อตกลงนั้นแล้ว | ย้ำกฎสำคัญซ้ำในข้อความล่าสุด (อย่าหวังให้จำ) |
| สรุปไฟล์ใหญ่แล้วพลาดส่วนท้าย | ไฟล์ยาวเกิน อ่านไม่ทั่ว | แบ่งไฟล์เป็นช่วง/ถามเจาะทีละหัวข้อ |

## เมื่อไหร่ทำอะไร (3 ท่าหลัก)

**แตกงาน (decompose)** — งานหลายสเต็ป/หลายไฟล์
- ทำทีละสเต็ป จบแล้วค่อยสเต็ปต่อไป; แต่ละสเต็ปใส่เฉพาะ input ของสเต็ปนั้น
- VERDICT: งาน >3 สเต็ป หรือต้องอ่าน >1 ไฟล์ใหญ่ → แตก ไม่ทำรวด

**สรุปย่อ (compact)** — แชตเดิมยังมีของดีแต่เริ่มล้น
- ให้ AI สรุป "สิ่งที่ตกลง/ทำเสร็จแล้ว" เป็น bullet สั้น → ใช้ก้อนนั้นเป็นจุดตั้งต้น
- VERDICT: เห็นสัญญาณลืม/วน 1-2 ครั้ง แต่ทิศยังถูก → สรุปย่อก่อน ยังไม่ทิ้งแชต

**เริ่มแชตใหม่ (reset)** — ปนกันจนแก้ไม่คุ้ม
- เปิดแชตใหม่ แปะเฉพาะ: เป้าหมาย + สรุปที่ล็อกแล้ว + ไฟล์ที่ยังต้องใช้
- VERDICT: วนซ้ำ/ขัดข้อตกลง ≥3 ครั้ง หรือสรุปย่อแล้วยังเพี้ยน → reset เลย อย่าฝืน

## จัดลำดับสิ่งที่ใส่เข้า context (ใส่อะไรก่อน-หลัง / อะไรไม่ใส่)

| ลำดับ | ใส่ | เพราะ |
|---|---|---|
| 1 | เป้าหมาย + เกณฑ์ "ผลที่ใช้ได้" | AI ต้องรู้ก่อนว่ากำลังทำอะไรให้ผ่าน |
| 2 | กฎ/ข้อจำกัดที่ห้ามพลาด (เช่น ISO 15189, รูปแบบ) | ของสำคัญไว้ใกล้คำถาม มันให้น้ำหนักมากกว่า |
| 3 | เฉพาะส่วนของไฟล์ที่เกี่ยวกับคำถามนี้ | ตัด noise ออก = แม่นขึ้น เร็วขึ้น |
| 4 | ตัวอย่าง 1 อันที่ "ใช่" | ยกคุณภาพมากกว่าใส่ข้อมูลดิบเพิ่ม |
| ❌ ไม่ใส่ | ไฟล์ทั้งเล่มทั้งที่ใช้แค่ 2 หน้า, ประวัติแชตเก่าไม่เกี่ยว, ข้อมูลเผื่อ "ไว้ก่อน" | กินที่ฟรี + ดัน noise + ดันของสำคัญตกขอบความจำ |

## กับดัก (Anti-patterns)
- **ลากงานทั้งโปรเจกต์ในแชตเดียว** — เริ่มแชตใหม่ตามสเต็ปดีกว่า ฝืนแชตเดียวจนเพี้ยน
- **เห็นมันลืมแล้วยังถมต่อ** — ยิ่งถมยิ่งล้น; ต้องสรุปย่อหรือ reset ไม่ใช่เพิ่ม
- **reset แล้วไม่พกสรุปไปด้วย** — เสียของที่ทำมา; ก่อนทิ้งแชต ดึงสรุปที่ล็อกแล้วออกมาก่อนเสมอ

## ช่องสำหรับผู้เชี่ยวชาญเติม
> เติมเคสจริงในสายงานคุณ เช่น:
> - *"(MT) แชตที่ผมให้ AI ช่วยร่าง WI/ตอบ NC แล้วมันเริ่มลืม ผมแก้ด้วยการ..."*
> - *"อัป PDF คู่มือ/SOP เล่มใหญ่แล้วมันอ่านไม่ทั่ว ผมแก้ด้วยการแบ่ง/ถามเจาะแบบ..."*
> - *"งานหลายสเต็ป (อ่านผล → สรุป → ร่างรายงาน) ผมแตกแชตแบบ... ได้ผลนิ่งสุด"*

ดูคู่กับ: `offload-to-automation` (เลข/ตาราง/ของซ้ำ โยนให้สคริปต์แทนยัดใน context) · `ai-assistant-calibration` (ตั้งค่าวิธีคุย AI ให้ตอบนิ่งตั้งแต่ต้น)
