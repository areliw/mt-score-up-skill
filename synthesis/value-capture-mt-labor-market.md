# ปัญหาราก MT = value-capture ไม่ใช่ oversupply

## Claim
"ล้นตลาด" เป็น **อาการ** ไม่ใช่โรค. รากคือ **value-capture**: วิชาชีพฝากคุณค่าทั้งหมดไว้กับ
**ช่องเดียว = เก้าอี้ bench ในโรงพยาบาล** ที่กำลัง *ล้น + ตัน + โดน automate + ไม่ได้ถือมูลค่าที่ตัวเองสร้าง* พร้อมกัน.

## หลักฐาน (สังเคราะห์จาก 6 signal-thread คอมมูฯ · de-identified)
1. **อาการผิว:** หางานไม่ได้ / บรรจุยาก / เงินต่ำ — 5/6 signal
2. **ช่องเดียว:** ทุกคนมุ่ง **เก้าอี้ ขรก.** — งานจริง *มี* (เอกชน/คลินิกแล็บ/รพช./QC/sale) แค่ไม่นับว่า "ได้งาน" → คอขวด = เก้าอี้แบบที่อยากได้ ไม่ใช่ "ไม่มีงาน"
3. **3 แรงบีบช่องนั้นพร้อมกัน:** supply↑ (23 สถาบัน · เปิดหลักสูตรง่าย ไม่คุมการผลิต) · demand ตัน (FTE cap / งบ / "รพ.กำลังเจ๊ง") · automation/POCT/AI ลดมือต่อหัว → ของล้น + ช่องตีบ = ถูกกดราคา (เศรษฐศาสตร์ตรงไปตรงมา)
4. **ราก — MT ไม่ได้ถือ value ที่ตัวเองสร้าง:** kit ธาลัสซีเมีย กำไรไปที่ **ผู้ผลิต** ไม่ใช่ bench · specialist เงิน ≈ ช่างซ่อมจบต่ำกว่าปริญญา · value ย้ายไป IVD-maker / genomics / AI — จุดที่ MT **ไม่ได้ยืน** (bench = ปลายทางที่ถูก commoditize + extract)
5. **มองไม่เห็น + ไม่มี pricing power:** lab = cost center → judgment ดีแค่ไหนก็ขายไม่ออก → ไม่มี leverage ขอเงิน (เทียบ x-ray: ได้เงินกว่าเพราะ **คุม production + link revenue ชัด** — MT ไม่มีทั้งคู่)

> **ประโยคเดียว:** "ล้นตลาด" แค่เปิดโปงปัญหา value-capture ที่มีมาตลอด — MT สร้างคุณค่าแต่ยืนผิดจุดในห่วงโซ่ จึงไม่ได้ถือมูลค่านั้น.

## นัย
- **ระดับบุคคล (ที่ hub ช่วยได้):** เลิกแย่งเก้าอี้ที่ถูกบีบ → ย้ายไปจุดที่ **capture value** — เป็นเจ้าของแล็บ/ธุรกิจ · commercial/industry ที่จ่ายตาม outcome ไม่ใช่หัว · genomics/AI/IVD ที่ value กำลังไป · judgment ที่ automate ไม่ได้
- **ระดับนโยบาย (นอก scope hub):** คุม production · ขยาย role นอกแล็บ · สร้างอุตสาหกรรม IVD ไทยที่ capture margin = เรื่องสภา/รัฐ ช้า + ไม่แน่ → **อย่ารอ**
- **meta:** doom-thread เอง = ส่วนหนึ่งของปัญหา (panic + bribe-rumor → ตัดสินจากอารมณ์) → งาน hub = ยื่น **แผนที่โครงสร้าง** แทนเสียง chorus

## Update 2026-06-24 — systemic dead-ends + entry-path data (จากบทสนทนายาว)

**1) Scarcity เป็น absolute ไม่ใช่ matching (ground-truth จากผู้เคยทำ job board เอง):** เปิดงานราว **20-30 ตำแหน่ง/เดือน** (~240-360/ปีที่ aggregate ได้) vs grad ใหม่ ~1500-1600/ปี + backlog = **~5:1 บน flow ใหม่**. **job board ตาย** เพราะงานโพสต์ในกลุ่ม FB (scrape ไม่ได้) + คนหางานก็อยู่ในกลุ่มนั้น → ไม่ใช่ปัญหา findability, **มันมีน้อยจริง**.

**2) AI = double squeeze:** supply↑ (สอบใบเฟ้อ ~48%→60%+, AI ช่วย cram) **+** demand↓ ที่ bench (automation) พร้อมกัน → ล้นเร็วกว่าเดิม. + **ใบประกอบเสื่อมเป็น signal** (ทุกคนผ่าน แยกเก่ง-ห่วยไม่ออก) เพราะเป็น **fixed-threshold ไม่ใช่ quota** → เฟ้อแล้วล้นไม่มีเบรก (ต่าง TCAS ที่ cutoff ปรับเอง).

**3) ไม่มี system fix — ตลาดเคลียร์เองแบบโหด:** ตัด supply ไม่ได้ (มหา'ลัยเติม quota ด้วยเด็กอ่อนลง · คนยังสมัครเพราะ MT = best-available ของเด็กที่เข้าหมอ/เภสัชไม่ได้) + เพิ่ม demand ไม่ได้ (ไม่มีเงิน) → เคลียร์ส่วนเกินด้วย **(ก) เงินเดือนถูกบดลง (ข) attrition คนทยอยออกจากวิชาชีพ** ใช้เวลาหลายปี.

**4) Root blocker = insider apathy:** institutional lever ตาย/บล็อกหมด เพราะ **คนถือ lever (ราชการ/กรรมการสภา-สมาคม) ปลอดภัยแล้ว ไม่มีเหตุผลลงมือ · คนเจ็บ (รุ่นน้อง) ไม่มีอำนาจ**. **สภา = single point ที่ fix เป็นไปได้จริง** (quality-gate: ไม่ accredit/ยกบาร์สอบ/moratorium = อำนาจที่มีจริง คนเดียวในระบบ) แต่ **politically suicidal** → ทุกนายกดัก. lever เดียวที่ capture ไม่ได้ = **organize คนเจ็บ** (crowdsource *ความเจ็บ* ไม่ใช่ *งาน* → ตัวเลข+คะแนนเสียง) — แต่ยากมาก (atomized · หนีเมื่อได้งาน).

**5) → ยืนยัน north-star ([[project_northstar_senior_collects_cases]]):** เมื่อ system แก้ไม่ได้จริง สิ่งเดียวที่ honest = **(ก) ช่วยบุคคลหนีไป edge (ข) บอกความจริงก่อนเข้าเรียน (mt-career Fork 10) เพื่อเร่ง correction ไม่หลอกคนใหม่เข้ามาเพิ่ม** — ไม่ใช่กอบกู้ระบบ (กู้ไม่ได้).

**6) ตอบคำถามเปิด "ย้ายสำเร็จกี่ %" — data-driven (6-path workflow + adversarial verify, 2026-06-24):** edge path ที่ **new grad ไม่มี ปสก. เสียบได้ตอนนี้จริง = แค่ 2/6** — (1) **แล็บเอกชน/เครือแล็บ** (base 16-22k `[✓src jobbkk]` · value-capture *ต่ำสุด* = ใช้เป็น runway) · (2) **IVD distributor sales** (base 14-17k+commission `[~est eduzones]` · value-capture *สูงสุดในกลุ่มที่เข้าได้* · เล็ง distributor ไทยไม่ใช่ principal). อีก 4 (genomics/CRA-CRC/regulatory-QA/IVF) = **value/ทน-AI ดี แต่ประตู opaque/ต้อง bridge 1-2 ปี → เป้าปี 2-3 ไม่ใช่ first job**. **บทเรียน: "value ย้ายไป edge" จริง แต่ edge แคบ/เข้ายากกว่าที่ vibe บอก — ต้องใช้ data ไม่ใช่ความหวัง.** (verified มี source จริงแค่ 2: เงินเดือน N Health + genomics shortage PMC; ที่เหลือ directional/modeled)
