# กระจายคอนเทนต์ข้ามแพลตฟอร์ม

ตัวช่วยตอน MT มีคอนเทนต์แล้ว อยากให้คนเห็น/เข้าถึงมากขึ้น (เพจให้ความรู้, แบรนด์วิชาชีพ, คลิปสอน) — เน้น "1 คอนเทนต์ → หลายแพลตฟอร์มแบบ native + ทำให้เจอ" ไม่ใช่ก๊อปแปะ

> **กฎ #1:** **1 คอนเทนต์หลัก → ดัดแปลงให้ native ต่อแพลตฟอร์ม** ไม่ใช่ก๊อปแปะเหมือนกันทุกที่
> **กับดัก #1 (ขั้น hard):** ก๊อปโพสต์เดียวแปะทุกแพลตฟอร์ม → engagement ตก (อัลกอริทึม/วัฒนธรรมต่างกัน); และ **เนื้อหา med ผิดที่เดียว = กระจายผิดไปทุกที่** → verify ก่อนกระจาย

> **verify-first:** decision-support ไม่ใช่คำตอบสุดท้าย — เช็คข้อเท็จจริงก่อนเชื่อ (คู่กับ `anti-hallucination`)

## ใช้เมื่อ
- มีคอนเทนต์ดีแต่คนไม่เห็น/ไม่ถึง
- อยากลงหลายแพลตฟอร์มแต่ไม่อยากทำใหม่ทุกอัน
- ไม่รู้จะปรับ/ตั้งเวลา/วัดผลยังไง

## วิธีใช้
วาง skill นี้ + คอนเทนต์หลัก + แพลตฟอร์มที่มี/อยากลง → AI ช่วยวาง repurpose plan ต่อแพลตฟอร์ม + discoverability + วัดผล แล้วชี้ให้ verify เนื้อหาเอง

---

## วิธีตัดสินใจ (AI: ทำตามนี้)

### Fork 1 — pillar → repurpose
- คอนเทนต์หลัก 1 ชิ้น → แตกเป็น: คลิปสั้น (Reels/TikTok/Shorts), thread/โพสต์ (X/Threads), carousel (IG/LinkedIn), บทความ (blog/LinkedIn), อินโฟกราฟิก

### Fork 2 — native ต่อแพลตฟอร์ม
- **TikTok/Reels**: hook 3 วิแรก, แนวตั้ง · **LinkedIn**: มืออาชีพ/insight + ข้อความนำ · **X**: สั้น/thread · **YouTube**: ยาว/ค้นเจอ · ปรับสำนวน+รูปแบบ ไม่ใช่แค่ crop

### Fork 3 — discoverability (SEO/social)
- title/keyword/hashtag ที่คนค้นจริง · thumbnail/ประโยคแรกที่ดึง · alt text/คำบรรยาย · ตั้งชื่อให้ค้นเจอ (เชื่อม `seo` ถ้ามีเว็บ)

### Fork 4 — timing + ความถี่
- ลงเวลาที่กลุ่มเป้าหมายออนไลน์ · สม่ำเสมอ > ถี่จน spam · มี content calendar คร่าวๆ

### Fork 5 — วัดผลให้ถูก
- engagement ที่หมายถึงอะไร (save/share > like สำหรับคุณค่า) · ดู trend ไม่ใช่ตัวเลขเดี่ยว (เชื่อม `content-creator-judgment`, `ab-test-judgment`)

### Fork 6 — accuracy + จรรยาบรรณ ทุกที่
- เนื้อหา med ถูก + disclaimer + ไม่เกินขอบเขต + ไม่เผยข้อมูลคนไข้ — **ในทุกแพลตฟอร์ม** (เชื่อม `mt-law-ethics-judgment`)

## กับดัก (Anti-patterns)
- #1 ก๊อปโพสต์เดียวแปะทุกที่ (ไม่ native) (กับดัก #1)
- #2 ละเลย format เฉพาะแพลตฟอร์ม (แค่ crop)
- #3 ไม่ทำ discoverability (title/hashtag/keyword)
- #4 โพสต์ถี่จน spam / ไม่สม่ำเสมอ
- #5 วัด vanity metric (like ล้วน) ตัดสินใจผิด
- #6 เนื้อหา med ผิด → กระจายผิดไปทุกแพลตฟอร์ม
- #7 ละเมิดลิขสิทธิ์ (เพลง/ภาพ) ตอน repurpose
- #8 ลงทุกแพลตฟอร์มจนทำไม่ไหว ไม่มีอันไหนดี

## ช่องสำหรับผู้เชี่ยวชาญเติม
> - แพลตฟอร์มที่กลุ่มเป้าหมายคุณอยู่จริง (ไม่ใช่ทุกที่)
> - คอนเทนต์ที่เคย performance ดี/แย่ → เรียนรู้ pattern
> - keyword/หัวข้อที่คนในสายคุณค้นหา

NOTE: ทำคอนเทนต์/เลือกหัวข้อ → `content-creator-judgment`; SEO เว็บ → `seo`; สร้างตัวตน → `personal-brand`; วัดผลแม่นๆ → `ab-test-judgment`
