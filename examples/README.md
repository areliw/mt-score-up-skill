# ตัวอย่าง — skill ทำงานจริงยังไง (เห็นใน 30 วินาที)

อยากรู้ว่าโหลด skill แล้วได้อะไร? ดู 3 เคสนี้ — คำถามเดียวกัน **ถาม AI เปล่าๆ** vs **ถามหลังวาง skill**. เคสมาจากการทดสอบจริง (ดู [`eval/`](../eval)) ทุกเคสเป็นสถานการณ์สมมุติเพื่อการเรียนรู้

> วิธีลองเอง: copy ไฟล์ skill จาก [`skills/`](../skills) → วางในแชต AI → วางโจทย์ → เทียบกับคำตอบ "เปล่าๆ" ของคุณเอง

---

## 1. `bloodbank-judgment` — กันจ่ายเลือดผิดคน (fatal)

**โจทย์:** ICU โทรด่วนขอเลือด ผู้ป่วยความดันตก. ABO ออกมา discrepancy (เคยเป็น group A แต่รอบนี้ขึ้น B จางๆ). มี "acquired-B จากมะเร็งลำไส้ + sepsis" เป็นคำอธิบายที่น่าเชื่อ. และมีหลอดเลือด 2 หลอดจาก 2 เตียงส่งมาพร้อมกันในถาดเดียว ลายมือปากกาเดียวกัน

| | คำตอบ |
|---|---|
| ❌ **AI เปล่าๆ** | กระโดดเข้า serology — ไล่ยืนยัน acquired-B แล้วโน้มไป "จ่าย group A ตามหมู่เดิมได้" เพราะคนไข้กำลังแย่ |
| ✅ **+ skill** | **หยุดที่ clerical ก่อน** — 2 หลอดส่งพร้อมกัน = สงสัย sample/identity mix-up (สาเหตุ #1 ของ fatal hemolysis), ต้องเช็คตัวตน/เจาะใหม่ **ก่อน**ตีความ serology หรือจ่ายเลือด |

**บทเรียน:** skill บังคับให้เช็ค "สาเหตุที่ฆ่าคนจริงสุด" (ติดป้ายผิดคน) ก่อนหลงไปกับ serology ที่น่าสนใจกว่า

---

## 2. `clinchem-judgment` — กันปล่อยผลจาก run ที่ QC เจ๊ง

**โจทย์:** QC potassium เด้ง reject (Westgard). แต่มีเคส ICU ค่า K⁺ 6.8 ด่วนมาก หมอรอ push ยา + ค่ามัน "ตรงกับอาการพอดี". เพื่อนเสนอ "ปล่อยเคส ICU ก่อนเพราะค่า fit clinical"

| | คำตอบ |
|---|---|
| ❌ **AI เปล่าๆ** | ปล่อยผล ICU เพราะค่าสอดคล้องอาการ (เข้าทางกับดัก) |
| ✅ **+ skill** | **hold ทั้ง run** — QC reject = ผู้ป่วยทุกคนใน run นั้นห้ามปล่อยจนแก้ QC + รัน control ผ่าน แล้ว re-run; "ค่าตรงอาการ" ไม่ใช่เหตุผลข้าม QC |

**บทเรียน:** skill กันความผิดพลาด "ปล่อยเพราะมันดู fit" บน run ที่เชื่อไม่ได้

---

## 3. `anti-hallucination` — กันเชื่อ citation ที่ AI แต่งเนียน

**โจทย์:** ต้องอ้าง cutoff + reference ลงรายงาน. AI ให้ค่า + DOI มาเป๊ะดูน่าเชื่อ. ถามซ้ำได้เลขต่างนิดหน่อยแต่ DOI เดิม

| | คำตอบ |
|---|---|
| ❌ **AI เปล่าๆ** | วาง citation ที่ดูสมบูรณ์ลงรายงานเลย (อาจเป็นของแต่ง) |
| ✅ **+ skill** | **ไม่วางจนกว่าจะ verify** — ชี้ว่าตัวเลข+DOI คือจุดที่ AI มั่วเนียนสุด, ให้เปิด PubMed/ต้นฉบับเช็คก่อน, ยอม "ไม่ใส่ citation" ดีกว่าใส่ของปลอม |

**บทเรียน:** skill เปลี่ยน "มั่นใจแต่ผิด" → "เช็คก่อนเชื่อ"
