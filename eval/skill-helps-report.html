กับดักที่ codex ชี้ว่าสกิลยัง "ขาด/overstate" (ต้องแก้ก่อน stable)

Scenario / datasetกับดักสกิล—สรุป
Optimize vs predict
warehouse-cost #3		เอา ML ไปแก้ปัญหาที่เป็น LP/ORoptimization-judgmentยังไม่รันโค้ดskill route ถูก (LP ไม่ใช่ ML) แต่ codex ชี้ overstate ('NP-hard→metaheuristic') ต้องแก้

Causal / observational
ai-students #2 · tiktok #8 · cancer #10		correlation≠causation บน survey/epi(ds-workflow ครอบบางส่วน)ยังไม่รันโค้ดGAP: confounding/survival ยังไม่ครอบ → signpost ก่อน stable

บทสรุป

  • สกิลช่วยจริงในกับดักที่วัดได้ 5/5 — naive ให้ตัวเลข "ดูดีแต่ลวง" ทุกเคส, แนวทางที่สกิลแนะนำเผยความจริง
  • แต่ยัง stable ไม่ได้ — codex จับ inaccuracy/overstate ในตัวสกิล + ขาด fairness/causal/p≫n signpost → คง draft จนแก้
  • กับดัก clinical (breast-cancer) = สกิลต้องเตือน "ห้าม deploy" ชัด — เหตุผลที่ medical-adjacent คง draft

เป้าหมาย loop: รอบนี้พิสูจน์ "กับดักมีจริง + สกิลแนะถูกทาง" → รอบหน้าแก้ inaccuracy ที่ codex จับ → re-run → promote เฉพาะที่ผ่าน
