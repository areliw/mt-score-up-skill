# จัดเวลาแบบ Time-Blocking รอบเวร

วางทุกชั่วโมงที่ตื่นให้มี "หมวด" — เอาเวรที่ fix แล้วเป็นโครง แล้วจัดชั่วโมงว่างด้วยความตั้งใจ ไม่ใช่ปล่อยให้อารมณ์เลือก

> **กฎข้อ 1:** วางของที่ fix ก่อนเสมอ (เวร เรียน เดินทาง พักฟื้นหลังเวร) → แล้วค่อยจัดงานหนัก (deep work) ลงช่อง "พลังงานสูง" ที่เหลือ. คนพลาดเพราะเอางานหนักไปยัดช่องที่ร่างพังพอดี (หลังเวรดึก/หลังเวรซ้อน) แล้วก็ทำไม่ออกทุกที.
> **กับดักข้อ 1:** จัดละเอียดทุกนาทีจน "แผนพัง = ล้มทั้งวัน". เวรมีสลับ มีงานแทรก มีร่างไม่ไหว — แผนที่ดีต้องเหลือ buffer + ปรับได้ทีละบล็อก ไม่ใช่ทิ้งทั้งวันเพราะพลาดบล็อกเดียว.

## ใช้เมื่อ
- มีวันที่ชน 3 อย่าง (เวร + เรียน + งานเสริม) แล้วไม่รู้จะเรียงยังไงให้ไม่พัง
- จะวางแผนพรุ่งนี้ / อาทิตย์นี้ / อาทิตย์หน้า ล่วงหน้า
- เห็นวัน OFF ว่างๆ แล้วอยากให้มันมีค่า ไม่ใช่หลุดไปกับการเลื่อนจอ
- รู้สึกอาทิตย์นี้ "ไหลๆ" — งานจุกจิก/แชต กินเวลางานสำคัญหมด
- **อย่าใช้เมื่อ:** กำลังไฟไหม้เฉพาะหน้า (ลงมือเลย วางแผนตอนนี้ = ผัดงาน) หรือดึกมากแล้ว (แผนตอนล้า = แผนคุณภาพต่ำ)

## วิธีใช้
วาง skill นี้ + บอก AI ว่าวันไหนมีเวรอะไร เริ่มกี่โมง เลิกกี่โมง ที่ไหน มีเรียน/งานเสริมอะไรบ้าง และเดินทางจากไหนถึงไหน → AI จะเรียงเป็นบล็อกรายชั่วโมงให้ พร้อมเผื่อเดินทาง+พักฟื้น แล้วบอกว่าช่องไหนควรเอางานหนักลง

## หมวดของบล็อก (จัดทุกชั่วโมงให้เข้าสักหมวด)

| หมวด | ความหมาย | ความยาวที่พบ |
|---|---|---|
| 🩺 เวร | งานในที่ทำงาน fix แล้ว | 6-8 ชม. |
| 🚌 เดินทาง | บ้าน↔ที่ทำงาน, ข้ามจังหวัด/อำเภอ | 30-90 นาที |
| 🍽️ พักฟื้น | กิน นั่งพัก ลดความล้าหลังเวร | 60-90 นาที |
| 🧠 งานหนัก (deep work) | วิจัย/วิทยานิพนธ์, อ่าน paper, โค้ดยากๆ | 90-150 นาที |
| 🛠 งานเบา (shallow) | เรียนออนไลน์, ทำงานเสริม, งานมีโครงชัด | 60-90 นาที |
| 📋 ธุรการ | อีเมล จดเงิน เคลียร์ inbox | 30-60 นาที |
| 🩹 ฟื้นร่าง | ยืดตัว เดิน งีบ ≤25 นาที อ่านเบาๆ | 30-90 นาที |
| 👨‍👩‍👧 ส่วนตัว | ครอบครัว เพื่อน ธุระ ออกกำลัง | ยืดหยุ่น |
| 😴 นอน | ห้ามต่อรอง | 7-8 ชม. |

## ลำดับวาง (ทำตามนี้ อย่าข้าม)
1. **วางของ fix ก่อน:** เวร เรียน นัด สอบ — ปักลงเส้นเวลาเป็นอันดับแรก
2. **เติมของที่ห้ามตัดของแต่ละวันเวร:** 🚌 เดินทางก่อน+หลัง · 🍽️ พักฟื้น 60-90 นาทีหลังเลิกเวร · 😴 นอน ≥7 ชม. ก่อนเวรเช้ารอบหน้า
3. **ปักงานสำคัญสุด 1-3 ของสัปดาห์ก่อนงานจุกจิก:** เรียงตาม "สำคัญ" ไม่ใช่ "เร่ง/ง่าย" — งานสำคัญ-ไม่เร่งคือตัวที่มักโดนเบียดหาย (busy ≠ productive). ปักลงช่องพลังงานสูงก่อน แล้วค่อยเติมงานเบา/ธุรการรอบมัน
4. **เอา 🧠 งานหนักลงช่องพลังงานสูง:** (ดูตารางจับคู่ด้านล่าง) อย่าเกิน 3 ชม./วัน
5. **เติมที่เหลือ:** 🛠 งานเบา / 📋 ธุรการ / 👨‍👩‍👧 ส่วนตัว ลงช่องว่าง — รวมธุรการเป็นบล็อกเดียว 30-60 นาที อย่ากระจายจนเป็นเศษ
6. **เช็กความจริง:** วันนี้รวมงานคิดเกิน 6 ชม.มั้ย? มีช่องฟื้นร่างมั้ย? เผื่อ buffer งานแทรกแล้วยัง?

## จับคู่งาน ↔ ช่วงพลังงาน (จัดงานหนักให้ตรงตอนพลังสูง)

| ประเภทวัน | ช่องพลังงานสูง = ลง 🧠 | ช่องพลังต่ำ = หลีกเลี่ยง 🧠 |
|---|---|---|
| วัน OFF | สาย 09:00-11:30 | บ่ายแก่ๆ หลังกินข้าวหนัก |
| วันเวรเช้า (เลิกเที่ยง) | บ่ายหลังพักฟื้น 14:00-16:00 | 30-90 นาทีแรกหลังเลิกเวร (ล้า) |
| วันเวรบ่าย | เช้า 09:00-11:00 ก่อนเข้าเวร | หลังเลิกเวรค่ำ (เหลือแค่ 🩹/😴) |
| วันหลังเวรดึก | — (ทั้งเช้าคือ 😴 ที่บ้าน) | ทั้งเช้า ห้ามจัดงานคิด |
| วันเวรซ้อน (เช้า+บ่าย/ปั่น) | — | ทั้งวัน + เช้าวันรุ่งขึ้น = 🩹 ฟื้นร่าง |

**VERDICT การเผื่อเวลา:** เดินทางข้ามอำเภอ/จังหวัด เผื่อจริง 45-60 นาที ไม่ใช่ 15 · หลังเวร เผื่อพักฟื้น 60-90 นาทีก่อนเริ่มงานคิด ไม่ใช่นับเป็น "ว่าง 90 นาที" · เวรเช้ารอบไกล ตื่นเผื่อเดินทาง+เตรียมตัวจริง ไม่ใช่ตื่นพอดีออก

**Theme day (ลดภาระตัดสินใจ):** กำหนดธีมให้แต่ละวันแทนสลับทุกชั่วโมง เช่น วัน OFF = วันวิจัย · วันเวรเช้า = วันเรียนออนไลน์ตอนบ่าย · 1 วัน/อาทิตย์ = วันฟื้นร่าง (ไม่มีงานหนักเกิน 60 นาที). ธีมช่วยให้สมองไม่ต้องเลือกใหม่ทุกครั้ง

**ปรับเมื่อแผนพัง (ไม่ใช่ล้มทั้งวัน):** เวรสลับ/งานแทรก/ร่างไม่ไหว → ขยับบล็อกที่เหลือ หรือยุบ 🧠 เป็น 🛠 เบาลง ไม่ใช่ทิ้งทั้งวัน. พลาด 1 บล็อก = ปรับ 1 บล็อก

## กับดัก (Anti-patterns)
- **จัดทุกนาทีไม่เหลือ buffer** — เวรมีสลับ ครอบครัวมีเรื่อง งานมีแทรก; แผนแน่นเป๊ะ = พังรอบเดียวล้มทั้งวัน
- **เอางานหนักไปวางหลังเวรทันที** — 60-90 นาทีหลังเวรร่างยังล้า ทำงานคิดไม่ออก แถมไปกินเวลานอน
- **เขียน 🧠 ว่า "ทำวิจัย" ลอยๆ** — ไม่ระบุว่า section ไหน = ไม่ได้ทำ; ตั้งเป็นงานชิ้นที่จับต้องได้
- **เอางานเสริม/อดิเรกไปแย่งช่วงเช้าที่พลังดีสุด** — ช่วงพลังสูงควรให้งานที่ ROI สูงกว่า
- **อัดงานคิดเกิน 6 ชม.ในวันมีเวร** — สุดท้ายไปแลกกับการนอน แล้ววันถัดไปพังต่อ
- **วางแผนใหม่ทุกวัน** — เปลืองพลังตัดสินใจ; วางทั้งอาทิตย์ทีเดียว แล้วปรับเฉพาะวันต่อวัน
- **ไม่เผื่อวันฟื้นร่าง** — ซ้อนงานหนัก 7 วันรวด สุดท้ายร่างพังแล้วหายไปทั้งอาทิตย์ ขาดทุนกว่าเดิม

## ช่องสำหรับผู้เชี่ยวชาญเติม
> เติมจากตารางเวรจริงของคุณ เช่น:
> - *"เวร [ประเภท] ของผม เลิกแล้วต้องพักฟื้นจริงกี่นาทีถึงทำงานคิดออก คือ..."*
> - *"ช่วงพลังงานสูงที่ทำงานหนักได้ดีที่สุดของผม คือ... (เพราะ...)"*
> - *"วันเวรซ้อนแบบ [...] ผมเรียนรู้ว่าวันรุ่งขึ้นต้องกันไว้เป็นวันฟื้นร่าง เพราะ..."*
