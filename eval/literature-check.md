# Literature cross-check — do the skills' key claims hold up?

> **Method.** For every clinical and methodology skill, an agent pulled the 3 most *falsifiable* claims, WebSearched a real authoritative source (AABB / ACOG / CLSI / KDIGO / NKF-ASN / guideline / peer-reviewed paper), and returned a verdict — `supported | nuanced | contradicted | unverified` — with the citation. Agents were told to be skeptical and to mark `unverified` rather than fabricate a source. This is Layer 1b of [`METHOD.md`](METHOD.md).

## Aggregate

**66 claims across 22 skills: 43 supported · 23 nuanced · 0 contradicted · 0 unverified.**

Zero claims were flat wrong, and zero were unverifiable hand-waves — but 23 came back *nuanced*, which is the signal that the check wasn't a rubber-stamp. Every nuance is a **currency/precision upgrade** (a dated method to demote, a cutoff to soften, a caveat to add), not a reversal. The actionable ones are folded into the skills or listed here for the expert to incorporate; none change a skill's core judgment.

> Scope: this pass covers clinical + research-methodology skills, where claims are checkable against a published canon. Business/finance/creative/AI-meta skills are validated instead by the audit (Layer 1) and the A/B (Layer 2) — see the honest **N/A** list at the bottom.

### clinchem-judgment
- **Claim 1 — Westgard 1₂ₛ is a warning rule only (don't reject on it; ~5% natural exceedance)** · verdict: nuanced · source: Westgard QC "Westgard Rules" / "Role of Rules" (westgard.com, current) · note: Correct historically — 1₂ₛ triggers inspection, not rejection, and lone-2SD false-reject is ~5% per level (9% at N=2); but the *modern* Westgard recommendation drops 1₂ₛ entirely and starts at 1₃ₛ. Skill should add "treat as warning OR omit per modern multirule."
- **Claim 2 — Hemolysis falsely elevates K⁺, LDH, AST → do not report** · verdict: supported · source: Lippi/Plebani "Influence of hemolysis on routine clinical chemistry" + Oxford Lab Medicine 2024 (acad.oup.com/labmed 55:5:624) · note: RBC intracellular K⁺ ~20–25× plasma; LDH/AST highly concentrated in RBC → leakage falsely raises all three; LDH/AST shift even below visual-hemolysis threshold, so rely on HIL index not eye. Correct.
- **Claim 3 — Bilirubin causes negative bias on Jaffe creatinine (skill: bili >10 → falsely low)** · verdict: nuanced · source: PMC4820417 (Indian J Clin Biochem 2016) + JALM 2019;4:477 · note: Direction is right (bilirubin→biliverdin under alkali drops 510nm absorbance → underestimates Cr); switch to enzymatic/SDS reagent is the correct fix. **Overall:** All three core claims hold up and none are dangerously wrong. Two need small caveats: 1₂ₛ should note modern multirule omits it (not just "warning"), and the bilirubin ">10" threshold is method-dependent — interference can start lower and enzymatic Cr isn't bilirubin-proof.

### chemistry-interpretation-judgment
- **Claim 1 — CKD-EPI 2021 (race-free) creatinine = default eGFR equation across all GFR ranges; cystatin C when Cr unreliable** · verdict: supported · source: NKF-ASN Task Force final report 2021 (JASN/AJKD 2021; Delgado et al.) + NKF Lab Engagement WG, Clin Chem 2022;68(4):511 · note: ASN/NKF (US) recommend CKD-EPI 2021 cr as first step and cystatin C as confirmatory when cr is near a decision point / less reliable — exactly as the skill states; note this is the US standard (KDIGO/some regions still allow others).
- **Claim 2 — Friedewald LDL (TC − HDL − TG/5) invalid when TG > 400 mg/dL → use direct LDL** · verdict: supported · source: original Friedewald 1972 (Clin Chem 18:499) + Martin et al. - **Claim 3 — AST:ALT ≥2:1 = alcoholic; AST>500 in a drinker = look for another cause (alcoholic usually <300)** · verdict: supported · source: Nyblom et al. 2004 (PMID 15208167; ratio>2 spec ~92%) + AAFP 1999 LFT review / Cleveland Clinic Hepatology · note: Ratio ≥2 + high GGT strongly suggests ALD; AST rarely >500 (usually 200–300) in pure alcoholic hepatitis, so >500 or ALT>200 should prompt an alternative etiology — matches skill precisely.

**Overall:** All three high-stakes claims hold up against current guidelines/literature. Only refinement worth adding: Friedewald underestimates LDL well below the 400 cutoff (starts ~150 mg/dL), so the >400 rule is a hard floor, not a guarantee of accuracy below it.

### choose-stat-test
- **Claim 1 — Method comparison needs Bland-Altman/ICC, not correlation; "r สูงแต่ bias ได้"** · verdict: supported · source: Bland & Altman, *Lancet* 1986 i:307-310 (PMID 2868172); reaffirmed Bland 2003 *Ultrasound Obstet Gynecol* DOI 10.1002/uog.122 · note: Pearson r measures linear association, not agreement — two methods can correlate near-perfectly (r=0.94) yet one reads consistently higher; LoA/ICC is the correct tool. Skill is exactly right.
- **Claim 2 — Use Welch as default for 2 independent groups (don't assume equal variance)** · verdict: supported · source: Delacre, Lakens & Leys 2017, *Int Rev Soc Psychol* 30(1):92-101, DOI 10.5334/irsp.82 · note: Welch controls Type-I error when variances differ and loses little power when they're equal; pre-testing variance is discouraged. Caveat the skill could add: with very unequal n + skew, neither is ideal (consider non-parametric) — but as a default Welch is endorsed.
- **Claim 3 — Chi-square needs all expected cells ≥5; else Fisher's exact (ห้ามปัด)** · verdict: nuanced · source: Cochran 1954; Kroonenberg & Verbeek 2018 *Am Stat* 72(2), DOI 10.1080/00031305.2017.1286260 · note: Correct for 2×2 (Cochran even wanted ≥10). **Overall:** All three core claims hold up; only fix is Claim 3 — add that the strict "all expected ≥5" applies to 2×2, while R×C tolerates ≤20% of cells <5 (none <1) per Cochran's rule.

### sample-size-power

**Overall:** All three core claims hold up against authoritative sources (Cohen/G*Power, WHO Lwanga-Lemeshow, Hoenig-Heisey); arithmetic is correct. No fixes needed — only optional caveats (16/d² is a z-approximation; add finite-population correction note for proportions).
