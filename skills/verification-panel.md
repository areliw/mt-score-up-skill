# ตั้งคณะตรวจ 3 มุม ก่อนเชื่อคำตอบ AI

ก่อนเชื่อคำตอบสำคัญ ให้ AI ตั้ง "คณะตรวจ 3 มุม" ที่พยายาม **หักล้างตัวเอง** ไม่ใช่ปรบมือให้ตัวเอง — เน้น **เจอจุดพังก่อนส่ง** ไม่ใช่ส่งไปแล้วค่อยรู้ว่าพลาด

> **กฎข้อ 1:** ตั้ง panel ให้ **ค้านไว้ก่อน (adversarial default)** — หน้าที่ของแต่ละมุมคือ "หาเหตุที่คำตอบนี้ผิด" ไม่ใช่ "ยืนยันว่าถูก". ถ้าทุกมุมพยายามค้านแล้วยังล้มไม่ลง = **น่าเชื่อขึ้น (ไม่ใช่พิสูจน์ว่าถูก)**. · ⚠️ 3 มุมจาก **โมเดลเดียว = ไม่ independent จริง** (แชร์ blind spot/training เดียวกัน) → เรื่องสำคัญ/คนไข้ต้องมี **หลักฐานนอก/คนจริง** ยืนยัน ไม่ใช่แค่ panel ผ่าน.
> **กับดักข้อ 1:** panel ที่เห็นด้วยกับตัวเอง = พิธีกรรมเปล่า. AI ตั้ง 3 มุมแล้วทุกมุมตอบ "โอเคแล้วครับ" คือไม่ได้ตรวจ — ได้แค่ตรายางปลอมความมั่นใจ. ทุกมุมเคลียร์ = ผ่าน *ชั้นกรองภายใน* เท่านั้น — ⚠️ **เรื่อง safety/คนไข้ "ทุกมุมเคลียร์" ยังไม่พอ** (3 มุมจากโมเดลเดียว = ไม่ independent) ต้องมี **หลักฐานนอก/คนจริง** ยืนยัน อย่าใช้ consensus ของโมเดลเป็นเกณฑ์ความปลอดภัย.

## ใช้เมื่อ
- คำตอบจะกระทบ **คนไข้ / ความปลอดภัย / เงิน / อาชีพ** (เช่น แปลผลแล็บ, ค่าวิกฤต, ตัวเลขในรายงาน QC)
- จะ **เผยแพร่สาธารณะ** หรือส่งให้คนอื่นใช้ต่อ (manuscript, WI/SOP, สไลด์สอน, โพสต์)
- มี **ตัวเลข / ค่าอ้างอิง / ชื่อสารหรือเชื้อ / citation** ที่ถ้าผิดแล้วเสียหาย
- คำตอบฟังดู "ลื่นเกินไป" / มั่นใจเกินจริง / ยาวจนไม่อยากไล่เอง
- เป็นการ **ตัดสินใจที่ย้อนยาก** (resign, ลงเงิน, ส่งผลออกระบบ)

## วิธีใช้
วาง skill นี้ → ให้คำตอบที่ร่างเสร็จ → สั่ง "ตั้ง panel 3 มุมแบบค้านไว้ก่อน" → AI จะสวมบทผู้ตรวจ 3 คนที่พยายามหักล้าง ออกผลทีละมุม (PASS / FAIL + เหตุ) แล้วสรุปว่า "ส่งได้" หรือ "ต้องกลับไปแก้ต้นทาง"

---

## คณะตรวจ 3 มุม (แต่ละมุมถามคนละคำถาม — ห้ามรวบเป็นคำเดียว)

| มุม | หน้าที่ (ค้านอะไร) | คำถามหลักที่ต้องตอบ | FAIL เมื่อ |
|---|---|---|---|
| 🔢 **Factual** | ตัวเลข/ค่า/ชื่อ/อ้างอิง จริงหรือแต่ง | "ค่านี้/ชื่อนี้/citation นี้ มาจากไหน ตรวจได้ไหม" | มีเลขหรือชื่อที่หาแหล่งยืนยันไม่ได้ |
| 🧩 **Logic/Consistency** | ขัดแย้งกันเอง / ข้ามขั้นตรรกะ | "ข้อสรุปต่อจากหลักฐานจริงไหม ขัดกับที่พูดไว้ก่อนหน้าไหม" | สรุปไม่ตามเหตุ หรือพูดสองอย่างที่ชนกัน |
| 🎯 **Context/Scope** | ตรงโจทย์จริง + อยู่ในขอบเขตวิชาชีพ/ความปลอดภัย | "ตอบตรงสิ่งที่ถามไหม อยู่ในขอบเขตที่ MT/AI ตอบได้ไหม" | ถูกแต่ผิดโจทย์ หรือล้ำเส้นวินิจฉัย/สั่งการรักษา |

**Verdict: 3 มุม = 3 คำถามคนละแบบ. รวมเป็นคำถามเดียว ("ตรวจให้หน่อย") → ได้คำตอบ generic ที่ไม่จับอะไรเลย.**

## ตั้ง panel ให้ adversarial จริง (ไม่ใช่แค่ติดป้าย)
- สั่งตรงๆ: *"สมมติคำตอบนี้ผิด — แต่ละมุมจงหาเหตุผลที่มันผิดมาให้ได้"*
- ห้ามตอบลอยๆ ว่า "ดูโอเค" — ต้องชี้จุดที่ตรวจ + เหตุผล. มุมที่ค้านไม่ลงจริงค่อยให้ผ่าน (ไม่ใช่ผ่านเพราะขี้เกียจค้าน)

## เกณฑ์ผ่าน + เจอปัญหาทำยังไง
**Verdict: เรื่อง safety/คนไข้ = ต้องผ่าน "ทุกมุม" ไม่ใช่เสียงข้างมาก. เจอจุดพัง = กลับไปแก้ต้นทาง ไม่ใช่แค่แปะหมายเหตุ.**

| สถานการณ์ | ทำอะไร |
|---|---|
| ทุกมุม PASS (ค้านแล้วไม่ล้ม) | ส่งได้ — แต่เรื่องการแพทย์/สำคัญ ยังต้องให้คน/แหล่งทางการยืนยันอีกชั้น |
| มุมใดมุมหนึ่ง FAIL | **กลับไปแก้คำตอบตรงต้นเหตุ** แล้ว run panel ใหม่ ไม่ใช่เติม "อนึ่ง อาจผิดได้" ทิ้งไว้ |
| 2 มุมผ่าน 1 มุมค้าน (เรื่อง safety) | ถือว่า **ไม่ผ่าน** — safety ไม่ใช้เสียงข้างมาก |
| ค้านกันเองไม่จบ | ยกขึ้นให้คนตัดสิน + ระบุชัดว่า "จุดไหนยังไม่ชัวร์" |

## AI เล็ก / แชตเปล่า ทำยังไง
**Verdict: ทำไม่ได้พร้อมกัน 3 มุม → ทำทีละมุมแทน ดีกว่าข้าม.**
- รันทีละ prompt: รอบ 1 ถามเฉพาะ Factual, รอบ 2 Logic, รอบ 3 Context
- เปิดแชตใหม่ให้ตรวจคำตอบเดิมแบบ "ไม่รู้ว่าใครเขียน" → ลด bias เข้าข้างตัวเอง
- ถ้าทำได้แค่มุมเดียว เลือก **Context/Scope** ก่อน (มุมที่คนข้ามบ่อยสุดและพังแรงสุดในงาน MT)

---

## กับดัก (Anti-patterns)
- **panel ที่เห็นด้วยกับตัวเอง** (ไม่ adversarial) → พิธีกรรมเปล่า ปลอมความมั่นใจ ไม่ได้ลดพลาดจริง
- **เอามาใช้กับงานจิ๊บจ๊อย** (ถามเล่น/ร่างหยาบ) → เปลืองเวลา; panel ไว้สำหรับงาน high-stakes เท่านั้น
- **เชื่อว่า "ผ่าน panel = ถูกแน่"** → panel ลดพลาด ไม่การันตีถูก; เรื่องคนไข้/สำคัญต้องมีคน/แหล่งยืนยัน
- **รวม 3 มุมเป็นคำถามเดียว** → ได้คำตอบ generic; ต้องแยกถาม Factual / Logic / Context คนละรอบ
- **ข้ามมุม Context/Scope** → คำตอบ "ถูกแต่ผิดโจทย์" หรือล้ำเส้นวิชาชีพ MT (เช่น ไปวินิจฉัย/สั่งรักษา) หลุดบ่อยสุด
- **ไม่นิยามเกณฑ์ "ดี" ให้ panel** → ตรวจลอยๆ ไม่รู้จะตกตรงไหน; บอกก่อนว่าคำตอบที่ใช้ได้ต้องมีอะไร
- **เจอ FAIL แล้วแค่ใส่หมายเหตุ** ("อาจคลาดเคลื่อน") แทนการแก้ → ต้นเหตุยังอยู่ คนอ่านต่อก็พลาดตาม

## ช่องสำหรับผู้เชี่ยวชาญเติม
> เติมเกณฑ์ตรวจเฉพาะสายงานคุณ เช่น:
> - *"(MT) ก่อนปล่อยผล/ส่งรายงาน QC ผมให้ panel เช็กว่า... ที่เคยพลาดคือ..."*
> - *"มุม Context ในงานแล็บของผม = ต้องไม่ล้ำเส้น...; เคยเจอ AI ตอบถูกแต่ผิดขอบเขตตรง..."*
> - *"citation/ตัวเลขที่ AI ชอบแต่งในงานวิจัยผม คือ... ผมจับด้วยมุม Factual โดย..."*

ใช้คู่กับ `anti-hallucination` (กันแต่งตั้งแต่ต้นทาง) และ `ai-agent-team` (ตั้ง panel เป็น "ฝ่ายตรวจสอบ" ของทีม) ได้
