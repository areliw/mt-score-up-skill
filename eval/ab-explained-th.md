# แต่ละ skill ช่วยอะไร — ฉบับภาษาคน

วิธีอ่าน: แต่ละอันเราเอา "กับดักที่คนชอบพลาดที่สุด" ของ skill นั้นมาตั้งเป็นโจทย์ แล้วดูว่า
AI ตัวอ่อนตอบดีขึ้นไหมเมื่อมี skill ช่วย

---

## 🟢 ช่วยชัดเจน — ไม่มี skill ตอบผิด, มี skill ตอบถูก (9 อัน)

1. **ivd-sales** — คนขายเครื่องแล็บชอบขายด้วย "เครื่องเราแม่นกว่า สเปกดีกว่า" → skill ทำให้ขายสิ่งที่หัวหน้าแล็บแคร์จริง (ลดงาน QC, ประหยัดน้ำยา, คุ้มต่อผลตรวจ)
2. **content-creator** — เลือกหัวข้อคลิปเพราะ "ข้อมูลครบ มีสาระ" แต่คนเลื่อนผ่านเพราะไม่มีจุดสะดุดให้หยุดดู → skill ทำให้เลือกหัวข้อที่มี "ตะขอ" ดึงคนดู
3. **anti-hallucination** — เชื่อคำตอบเพราะมันพูดมั่นใจ + มีเลขเป๊ะ + อ้างอิงสวย (ทั้งที่มั่ว) → skill ทำให้ "เช็กก่อนเชื่อ"
4. **mt-exam-strategy** — อ่านหนังสือสอบทุกวิชาเท่ากันตามใจชอบ → skill ทำให้ทุ่มเวลาให้วิชาที่ออกข้อสอบเยอะก่อน (คุ้มแต้มกว่า)
5. **polite-but-clear** — เขียนข้อความสุภาพจนจับใจความไม่ได้ (เคสนี้ค่าโพแทสเซียมอันตราย แต่เขียนนุ่มจนหมอไม่รีบ) → skill ทำให้สุภาพแต่ยังเห็นชัดว่า "ด่วน อันตราย รักษาเดี๋ยวนี้"
6. **mt-career** — เทียบงานขายกับงานแล็บด้วย "เงินเดือนฐาน" อย่างเดียว → skill ทำให้ดูทั้งก้อน (คอมมิชชั่น + ค่าเดินทาง + โบนัส)
7. **r2r-research-proposal** — เริ่มเก็บข้อมูลวิจัยก่อน ค่อยขอจริยธรรมทีหลัง (ผิด) → skill ทำให้ขออนุมัติก่อนแตะตัวอย่างแรก
8. **ikigai-finder** — เชื่อ "สิ่งที่ปากบอกว่ารัก" (วาดรูป) ทั้งที่ 2 ปีไม่เคยวาด → skill ทำให้ดู "สิ่งที่ทำจริง" (ชอบสอน/อธิบาย)
9. **sample-size-power** — คำนวณ "พลังการทดสอบย้อนหลัง" จากผลที่ได้ (วิธีที่ผิด) → skill ทำให้รู้ว่าอย่าทำ

## 🟢 ช่วยให้ดีขึ้น — ทั้งคู่ตอบถูก แต่มี skill ตอบครบ/คมกว่า (16 อัน)

- **parasitology** — ตรวจอุจจาระครั้งเดียวไม่เจอ ≠ ไม่มีพยาธิ (มันออกเป็นช่วง) ต้องตรวจซ้ำ
- **clinical-correlation** — ซีดในผู้หญิงมีประจำเดือน ≠ ขาดเหล็กเสมอ → ดูค่าเหล็กจริง = ธาลัสซีเมีย
- **pharmacology** — แยก "ผลข้างเคียงธรรมดา" กับ "แพ้ยารุนแรง" (ผื่น+ไข้+เจ็บคอ หลังยาเกาต์ = อาจ SJS)
- **molecular** — "ไม่ขึ้นสัญญาณ" ≠ "ผลลบ" ถ้าตัวควบคุมไม่ผ่าน (เลือดมี heparin รบกวน) → เจาะใหม่
- **chemistry-interpretation** — อย่าใช้ค่ามะเร็ง (tumor marker) คัดกรองคนปกติ ค่าสูงนิดเดียว ≠ มะเร็ง
- **financial-statement** — กำไรโตสวยอย่างเดียวไม่พอ ดูเงินสดจริงด้วย ลูกหนี้บวมผิดปกติ = สัญญาณอันตราย
- **marketing** — ลูกค้าเงียบไม่ใช่เพราะของไม่ดีพอ แต่ขี้เกียจเปลี่ยน อย่าตะโกนสเปกดังขึ้น
- **sales-psychology** — อย่าสู้สงครามสเปก อ่านแรงจูงใจคนซื้อ (เคสนี้ = ศักดิ์ศรี/ภาพลักษณ์)
- **self-development-coach** — อย่าปลอบอย่างเดียว ชี้จุดจริง ("เตรียมตัวอีกหน่อย" = ข้ออ้างไม่กล้าสมัคร)
- **ml-judgment** — อย่าจัดข้อมูล/เลือกตัวแปรบนข้อมูลทั้งก้อนก่อนแบ่งฝึก-ทดสอบ (ได้คะแนนปลอม)
- **research-design** — งานวิจัยวัดครั้งเดียว บอกได้แค่ "เกี่ยวข้องกัน" ไม่ใช่ "เป็นต้นเหตุ"
- **optimization** — อย่าลืมเงื่อนไขที่ซ่อนในประโยค ไม่งั้นคำตอบใช้จริงไม่ได้
- **critical-appraisal** — อย่าอ้างผลที่เปเปอร์ไม่ได้พูด (อ่าน abstract แล้วเวอร์เกินจริง)
- **data-project-survival** — อย่ากระโดดทำโมเดลก่อนเข้าใจปัญหา ("มี data แล้วค่อยหาโจทย์" = ผิด)
- **ai-assistant-calibration** — AI เข้าใจผิดซ้ำๆ อย่าโทษว่ามันโง่ → แก้คำสั่งให้เจาะจงขึ้น
- **photography** — ตั้งโจทย์ว่าภาพจะสื่ออะไรก่อนยกกล้อง (ทั้งคู่ยังไม่เก่ง แต่มี skill ดีกว่านิด)

## ⚪ พอๆ กัน — AI รู้อยู่แล้ว ไม่ต่าง (19 อัน)

ส่วนใหญ่เป็นเรื่องแล็บ/พื้นฐานที่ AI ตอบถูกเองอยู่แล้วในโจทย์เดียว — value ของ skill อยู่ตอน
"บังคับให้เช็กทุกครั้ง" + เคสยากกว่านี้ ซึ่งโจทย์เดียววัดไม่ออก:

choose-stat-test · mt-law-ethics · pathology · hematology · clinmicro · immunoassay ·
applied-microbiology · lab-management · crm · cv · db · python-coach · r2r-stats ·
finance · manuscript · explain-simply · progress-tracker · self-improving-agent · what-skill-do-i-need

## 🟡 เสียคะแนนนิดเดียว — แต่ยังตอบถูก ไม่อันตราย (7 อัน)

ทั้งสองเวอร์ชันตอบถูก มี skill แค่เขียนยาว/สไตล์ต่าง เลยโดนกรรมการหักนิดเดียว **ไม่ใช่ผิด**:

- **bloodbank** — เช็กฉลากคนไข้ก่อนเสมอ (ป้องกันให้เลือดผิดคน) ✓ ทั้งคู่ถูก
- **infection-control** — ล้างมือด้วยสบู่หลังเคส C.diff เพราะแอลกอฮอล์ไม่ฆ่าสปอร์ ✓ ทั้งคู่ถูก
- **toxicology** — ต้องยืนยันด้วยเครื่อง GC-MS ก่อนรายงานผลบวก ✓ ทั้งคู่ถูก
- **clinchem** — รัน QC ไม่ผ่าน ห้ามปล่อยผลคนไข้ ✓ ทั้งคู่ถูก
- **digital-judgment** — ลบแค่ชื่อ/HN ยังไม่พอ (รหัสไปรษณีย์+วันเกิด+เพศ ตามตัวคนได้) ✓ ทั้งคู่ถูก
- **never-lose-a-file** — ไฟล์เกลื่อนไม่ใช่ปัญหา "ตั้งชื่อ" แต่ปัญหา "ไม่มีบ้านเดียว" ✓ ทั้งคู่ถูก
- **ai-agent-team** — ติดป้ายหลายตำแหน่งแต่ AI ตัวเดียวคิด = ไม่ได้ตรวจกันจริง ✓ ทั้งคู่ถูก

## 🔴 ไม่ช่วย — ทั้งคู่ตกหลุม (2 อัน)

บทเรียนคมสุด: 2 อันนี้เป็น skill แบบ "ต้องลงมือทำ" ไม่ใช่ "แค่รู้" — อ่านคำแนะนำเฉยๆ ไม่พอ

- **know-yourself** — ทั้งคู่ได้ข้อมูลแค่ "ทำหน้าที่อะไร" ไม่ขุดตัวเลข/เรื่องราว → เรซูเม่จืด. skill นี้
  ต้องถาม-ตอบหลายรอบจริงถึงเวิร์ก เอามาอ่านรอบเดียวไม่พอ
- **offload-to-automation** — โจทย์จัดตารางที่ต้องใช้เครื่องคิด แต่ AI คิดในหัวแล้วมั่นใจ (ผิด). skill บอกให้
  "ส่งให้ตัวช่วยคำนวณ" แต่ AI ตัวอ่อนอ่านแล้วก็ยังคิดในหัวอยู่ดี — ต้องต่อเครื่องมือจริงถึงได้ผล

แต่คำตอบยังถูก (7 อัน). ศูนย์อันตราย
