# บริหารเวลา/โฟกัส สำหรับ MT เวรหมุน

ตัวช่วยตอน MT ต้องจัดเวลา/โฟกัส ทั้งงานเวร + เรียน/ทำโปรเจกต์/ทำคอนเทนต์ข้างงาน — เน้น "จัดตามสำคัญ + วางแผนรอบเวร" ไม่ใช่ระบบ productivity สำหรับชีวิต 9-5

> **กฎ #1:** จัดลำดับตาม **"สำคัญ"** ไม่ใช่ "เร่ง/ง่าย" — และปกป้องช่วง **deep work** ไว้ก่อนงานจุกจิก
> **กับดัก #1 (ขั้น hard):** ทำงานง่าย/เร่งให้รู้สึก productive แต่งานสำคัญไม่ขยับ (**busy ≠ productive**); และ plan แบบ fix เวลาเดิมทุกวัน **พังกับเวรหมุน** → ต้องวางแผนเป็นรอบตามชนิดเวร

> **verify-first:** decision-support ไม่ใช่คำตอบสุดท้าย — เช็คข้อเท็จจริงก่อนเชื่อ (คู่กับ `anti-hallucination`)

## ใช้เมื่อ
- งานเวร + เป้าหมายส่วนตัว (เรียน/วิจัย/คอนเทนต์) ชนกัน ไม่มีเวลา
- รู้สึกยุ่งทั้งวันแต่งานสำคัญไม่เดิน
- เวรหมุนทำให้จัดตารางไม่ลง

## วิธีใช้
วาง skill นี้ + ตารางเวร + เป้าหมาย/งานที่ต้องทำ → AI ช่วยจัดลำดับ + วาง time-block รอบเวร + ชี้กับดัก busy-not-productive

---

## วิธีตัดสินใจ (AI: ทำตามนี้)

### Fork 1 — priority ก่อนตาราง
- เลือก **"สิ่งสำคัญสุด 1–3 อย่างของสัปดาห์"** · แยกสำคัญ vs เร่ง (สำคัญ-ไม่เร่ง = ที่มักโดนเบียด) · ตัด/มอบ/เลื่อน ที่ไม่สำคัญ

### Fork 2 — time-block รอบเวร (ไม่ใช่ 9-5)
- ทำ template ต่อชนิดเวร: **หลังเวรดึก** (พักก่อน, งานเบา) · **เวรเช้า/บ่าย** (deep work ช่วง off) · **วันหยุด** (งานก้อนใหญ่) — แมตช์งานกับพลังงานที่เหลือ

### Fork 3 — deep work / pomodoro
- กันเวลา deep work เป็นบล็อก (25–90 นาที) · 1 งานต่อบล็อก · ปิดแจ้งเตือน · งานยาก = ทำตอนพลังงาน peak ของคุณ

### Fork 4 — กัน distraction
- มือถือ/แชต/social = ตัวกินโฟกัส → ตั้ง do-not-disturb, แยกเวลาเช็ก, ใช้ `offload-to-automation` กับงานซ้ำ

### Fork 5 — พลังงาน + กัน burnout
- เวรหมุน + เรียน = เสี่ยง burnout → จัดพัก, นอนให้พอ (ปรึกษาแพทย์เรื่องการนอนเป็นกะ), อย่าอัดทุกช่วงว่าง · ความสม่ำเสมอเล็กๆ ชนะ sprint แล้วพัง

### Fork 6 — realistic
- ประเมินเวลาเผื่อจริง (งานมักนานกว่าคิด) · **อย่า overcommit** · ทบทวนปลายสัปดาห์ + ปรับ

## กับดัก (Anti-patterns)
- #1 ทำง่าย/เร่งก่อนสำคัญ — busy ไม่ productive (กับดัก #1)
- #2 plan แบบ fix 9-5 ทั้งที่เวรหมุน
- #3 overcommit จนไม่จบอะไรเลย
- #4 ไม่กัน distraction (มือถือ/แชต)
- #5 ทำงานยากตอนหมดแรง (หลังเวรดึก)
- #6 ไม่พัก/อัดทุกช่วงว่าง → burnout
- #7 to-do ยาวไม่จัดลำดับ
- #8 ไม่ทบทวน/ปรับ → ทำผิดวิธีซ้ำ

## ช่องสำหรับผู้เชี่ยวชาญเติม
> - ตารางเวรจริงของคุณ (รูปแบบหมุน) + ช่วงที่พลังงานดีสุด
> - เป้าหมายข้างงานที่สำคัญสุดตอนนี้ (เรียน/วิจัย/คอนเทนต์)
> - งานซ้ำที่กินเวลาแต่ automate/มอบหมายได้

NOTE: โยนงานซ้ำให้ระบบ → `offload-to-automation`; วางแผนโปรเจกต์ใหญ่ → `plan-with-ai`; พัฒนาตัวเองภาพรวม → `self-development-coach`
