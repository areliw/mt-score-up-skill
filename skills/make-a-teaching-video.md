# ทำคลิปสอน/explainer สำหรับ MT

ตัวช่วยตอน MT ทำคลิปสอน (เทคนิค/SOP, อธิบาย concept, สอนน้อง/นักเรียน, คอนเทนต์ให้ความรู้) — เน้น "วางให้ผู้เรียนทำได้ + ปลอดภัยตามจรรยาบรรณ" ไม่ใช่สอนตัดต่อ

> **กฎ #1:** คลิปสอนเริ่มที่ **"ผู้เรียนต้องทำอะไรได้หลังดู" (learning objective)** + มี script ไม่ใช่เปิดกล้องพูดเรื่อยๆ
> **กับดัก #1 (ขั้น hard):** เอา **ภาพคนไข้/ผล/HN/สไลด์เคสจริง** ลงคลิป public = ผิด **PDPA + จรรยาบรรณ** → de-identify / ขออนุญาต / ใช้ตัวอย่างสมมุติ; เนื้อหา med ต้องถูก + มี disclaimer (เชื่อม `mt-law-ethics-judgment`, `digital-judgment`)

> **verify-first:** decision-support ไม่ใช่คำตอบสุดท้าย — เช็คข้อเท็จจริงก่อนเชื่อ (คู่กับ `anti-hallucination`)

## ใช้เมื่อ
- ทำคลิปสอนเทคนิค/SOP/concept ให้ทีม/นักเรียน/ผู้ติดตาม
- คลิปยาว/น่าเบื่อ/คนดูไม่จบ ไม่รู้ปรับยังไง
- กังวลเรื่องข้อมูลคนไข้/ลิขสิทธิ์/ความถูกต้อง

## วิธีใช้
วาง skill นี้ + บอกหัวข้อ + กลุ่มเป้าหมาย + ความยาว → AI ช่วยตั้ง objective + ร่าง script/storyboard + เตือน PDPA/จรรยาบรรณ/ลิขสิทธิ์ แล้วชี้ให้ verify เนื้อหาเอง

---

## วิธีตัดสินใจ (AI: ทำตามนี้)

### Fork 1 — objective + กลุ่มเป้าหมาย
- จบคลิปผู้เรียน **ทำอะไรได้/รู้อะไร** (1–3 ข้อ) · ใครดู (นักเรียน/เพื่อนร่วมงาน/ประชาชน) → ปรับระดับภาษา (เชื่อม `explain-simply`)

### Fork 2 — script / storyboard
- โครง: **hook (ทำไมต้องดู) → เนื้อ (ทีละ step) → สรุป + ทำต่อ** · เขียน script ก่อนถ่าย (กันเยิ่นเย้อ) · สั้นเข้าไว้ (ตัดทุกอย่างที่ไม่ช่วย objective)

### Fork 3 — เลือกรูปแบบ
- **screen recording** (ซอฟต์แวร์/LIS) · **talking head** (เล่า/สาธิต) · **animation/manim** (อธิบาย concept/กลไก) · **slide + เสียง** (เริ่มง่ายสุด) — เลือกตามเนื้อหา + เวลาที่มี

### Fork 4 — ความถูกต้อง + แหล่ง
- เนื้อหา med **verify กับตำรา/guideline** + ระบุแหล่ง · ใส่ **disclaimer** เมื่อเป็นความรู้ที่คนเอาไปใช้กับตัว/คนไข้

### Fork 5 — ความปลอดภัย/กฎหมาย
- **de-identify** ทุกภาพ/ผล/เคส (ไม่มี HN/ชื่อ/หน้า) · ขออนุญาตถ้าใช้ของจริง · **ลิขสิทธิ์** เพลง/ภาพ/วิดีโอ (ใช้ free-license) · ไม่ทำให้ที่ทำงาน/คนเสียหาย

### Fork 6 — คุณภาพ + เผยแพร่
- เสียงชัด > ภาพสวย · subtitle ช่วยการเข้าถึง · จบด้วย call-to-action · กระจายต่อ → `content-distribution`

## กับดัก (Anti-patterns)
- #1 ภาพ/เคส/ผลคนไข้จริงไม่ de-identify (กับดัก #1)
- #2 ไม่มี objective → คลิปเปะปะ
- #3 ยาว/เยิ่นเย้อ ไม่มี script → คนดูไม่จบ
- #4 เนื้อหา med ผิด/ไม่มี disclaimer/ไม่ verify
- #5 เนื้อหาเกินขอบเขตวิชาชีพ (วินิจฉัย/สั่งยา)
- #6 ละเมิดลิขสิทธิ์เพลง/ภาพ
- #7 เสียง/ภาพแย่จนตามไม่ทัน
- #8 ไม่มี call-to-action/ทำต่อ

## ช่องสำหรับผู้เชี่ยวชาญเติม
> - หัวข้อ + กลุ่มผู้เรียน + แพลตฟอร์มที่จะลง
> - นโยบาย รพ./สถาบันเรื่องการถ่ายในที่ทำงาน + ข้อมูลคนไข้
> - แหล่ง free-license ที่คุณใช้ (เพลง/ภาพ) + ตำราที่ใช้ verify เนื้อหา

NOTE: how-to ตัดต่อ/โปรแกรม (CapCut/Premiere/manim/remotion) → คู่มือ/ถาม AI แยก; อธิบายให้ง่าย → `explain-simply`; กระจายคลิป → `content-distribution`
