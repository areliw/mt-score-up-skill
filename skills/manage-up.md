# คุยกับหัวหน้าให้ได้ผล (Manage Up)

ตัวช่วยตอน MT ต้องคุยขึ้นบน — ขออัตรากำลัง/เครื่อง/งบ, แจ้งปัญหา/ความเสี่ยง, เสนอปรับปรุง/ไอเดีย, ขอ feedback — เน้น "เตรียมให้ผ่าน + พูดภาษาหัวหน้า" ไม่ใช่บ่น

> **กฎ #1:** สื่อสารด้วย **"ปัญหา + ทางออก + ผลกระทบ + ข้อมูล"** ไม่ใช่บ่นปัญหาเฉยๆ — และเข้าใจ priority/แรงกดดันของหัวหน้า
> **กับดัก #1 (ขั้น hard):** รายงานแต่ปัญหา **ไม่มีทางออก/ไม่มีข้อมูล** = ถูกมองว่าบ่น; เสนอแบบ **ไม่มี impact เป็นตัวเลข** = ไม่ผ่าน → ใส่ data + ทางเลือก + ผลต่อสิ่งที่หัวหน้าแคร์ (เงิน/ความเสี่ยง/คุณภาพ/เวลา) (เชื่อม `ivd-sales-judgment`, `management-talk`)

> **verify-first:** decision-support ไม่ใช่คำตอบสุดท้าย — เช็คข้อเท็จจริงก่อนเชื่อ (คู่กับ `anti-hallucination`)

## ใช้เมื่อ
- จะขอทรัพยากร (คน/เครื่อง/งบ/น้ำยา/เวลา)
- ต้องแจ้งปัญหา/ความเสี่ยง/ข่าวร้าย
- จะเสนอปรับปรุง/ไอเดียใหม่ หรือขอ feedback/เลื่อนตำแหน่ง

## วิธีใช้
วาง skill นี้ + เป้าหมายการคุย + บริบท (ปัญหา/สิ่งที่อยากได้/ข้อมูลที่มี) → AI ช่วยเรียบเรียงเป็น "ปัญหา+ทางออก+impact" ภาษาหัวหน้า + เตือน timing/ขอบเขต

---

## วิธีตัดสินใจ (AI: ทำตามนี้)

### Fork 1 — เป้าหมายการคุยให้ชัด
- อนุมัติ? ขอของ? แจ้งเตือน? ขอ feedback? → 1 เป้าต่อการคุย, ขอให้ชัด ("ผมขอ ... ภายใน ...")

### Fork 2 — เตรียมก่อนเข้าคุย
- **ปัญหา (สั้น) + ทางออก 1–3 ทาง + ข้อแนะนำ + impact + ข้อมูลหนุน** · เตรียมตอบ "ถ้าไม่ทำจะเกิดอะไร"

### Fork 3 — พูดภาษาหัวหน้า
- แปลงเป็นสิ่งที่หัวหน้าแคร์: **เงิน (cost/ROI) · ความเสี่ยง (คุณภาพ/ความปลอดภัย/accreditation) · เวลา (TAT) · คน** (เชื่อม `ivd-sales-judgment` คิดแบบ budget-pocket)

### Fork 4 — timing + ช่องทาง
- เลือกเวลาที่หัวหน้าพร้อมฟัง (ไม่ใช่ตอนวิกฤต) · เรื่องใหญ่คุยตัวต่อตัว/มีนัด ไม่ใช่แชตยาว · เตรียม 1 หน้าสรุป

### Fork 5 — แย้ง/บอกข่าวร้ายอย่างปลอดภัย
- แย้งด้วยข้อมูล + เคารพ, ไม่ใช่ต่อหน้าคนอื่น (เชื่อม `polite-but-clear`) · ข่าวร้ายบอกเร็ว + พร้อมแผนรับมือ

### Fork 6 — ขอบเขต + การเมืององค์กร + follow-up
- รู้ว่าใครตัดสินใจ/ใครมีอิทธิพล · ไม่ข้ามหัว (skip-level) พร่ำเพรื่อ · สรุปสิ่งที่ตกลง + **follow-up** เป็นลายลักษณ์

## กับดัก (Anti-patterns)
- #1 บ่นปัญหาไม่มีทางออก/ไม่มี data (กับดัก #1)
- #2 พูดภาษาตัวเอง (เทคนิค) ไม่ใช่ภาษาหัวหน้า (เงิน/เสี่ยง)
- #3 timing ผิด (ขอตอนหัวหน้าเครียด/งบปิดแล้ว)
- #4 แย้ง/วิจารณ์ต่อหน้าคนอื่น
- #5 over-promise เพื่อให้ผ่าน
- #6 ข้ามหัวหน้าไปหา level บน พร่ำเพรื่อ
- #7 ไม่ follow-up → เรื่องเงียบ
- #8 ขอแบบกว้าง ("อยากได้เครื่องใหม่") ไม่มีตัวเลข/เหตุผล

## ช่องสำหรับผู้เชี่ยวชาญเติม
> - สิ่งที่หัวหน้าคุณแคร์สุด (งบ/accreditation/TAT/อัตรากำลัง) + สไตล์การตัดสินใจ
> - ข้อมูล/ตัวเลขที่คุณมีหนุนคำขอ
> - การเมือง/ลำดับการอนุมัติในองค์กรคุณ

NOTE: ปรับถ้อยคำให้สุภาพแต่ชัด → `polite-but-clear`; คิดแบบ buyer/budget → `ivd-sales-judgment`; ภาวะผู้นำ/ทีมเชิงลึก → `management-talk`
