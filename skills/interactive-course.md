# ให้ AI ติวแบบ interactive ทีละขั้น

เปลี่ยน AI จาก "เครื่องเทเนื้อหายาว" → **ติวเตอร์ที่พาเดินทีละขั้น** — อธิบายสั้น → หยุดถามเช็ค → ปรับระดับตามคำตอบ ไม่ใช่ lecture รวดเดียวจบ

> **กฎข้อ 1:** บังคับ AI ให้ **หยุดทุกขั้นเพื่อรอคำตอบเรา** ก่อนไปต่อ — "อธิบาย 1 จุด → ถาม 1 คำถามเช็คความเข้าใจ → รอเราตอบ → ค่อยไปจุดถัดไป" คนที่คุมจังหวะคือเรา ไม่ใช่ AI. เราเรียนได้เพราะ "ตอบเอง" ไม่ใช่เพราะ "อ่านที่มันเท".
> **กับดักข้อ 1:** AI ชอบ lecture ยาวรวดเดียวแล้วถามลอยๆ ท้าย ("เข้าใจไหม") — นั่นคือเอกสาร ไม่ใช่การติว. และมันสอน **ผิดได้อย่างมั่นใจ** (โดยเฉพาะค่าตัวเลข/กลไก/เกณฑ์แล็บ) ของวิชาการ/การแพทย์ **ต้อง cross-check ตำราเสมอ** อย่าเชื่อเพราะมันพูดลื่น.

## ใช้เมื่อ
- ติวสอบใบประกอบ MT — อยากให้พาไล่ทีละหัวข้อ + quiz เช็คเป็นช่วง ไม่ใช่อ่านสรุปยาว
- เรียนหัวข้อ DS/สถิติที่ยาก (เลือก test, p-value, regression) — อยากเข้าใจจริงทีละสเต็ป
- เจอ concept ยากที่อ่านเองแล้วงง อยากให้ "เดินช้าๆ" จนเข้าใจก่อนไปต่อ
- อยากให้ปรับความยากตามเรา — ตอบถูก = เร่ง, ตอบพลาด = ถอยมาอธิบายใหม่
- ทบทวนก่อนสอบด้วย recall/quiz (ดึงความจำออกมาเอง) แทนการนั่งอ่าน passive

## วิธีใช้
วาง skill นี้ + บอก **หัวข้อ + ระดับตัวเอง (มือใหม่/ทวน)** เช่น *"ติวเรื่อง [X] แบบ interactive ทีละขั้น อธิบายสั้นแล้วถามเช็คทีละจุด"* → AI จะอธิบายทีละชิ้น หยุดถามเรา รอคำตอบ แล้วปรับระดับให้

ไหลแบบนี้:
1. บอกหัวข้อ + ระดับ (มือใหม่ / ทวนก่อนสอบ / งงเฉพาะจุด)
2. AI อธิบาย **1 concept** สั้นๆ + analogy แล้วหยุดถาม 1 คำถาม
3. เราตอบ → AI ปรับ: ถูก = ไปต่อ, พลาด = อธิบายใหม่คนละมุมแล้วถามซ้ำ
4. ทุก 3-4 จุด ให้มัน quiz ทวนสั้นๆ
5. ถ้ามันเทยาว/ไม่ถาม → พิมพ์ *"หยุด ถามทีละข้อ"* ดึงกลับเข้าจังหวะ
6. ของวิชาการ/ตัวเลข → สั่งให้มัน flag จุดที่ต้อง verify กับตำรา

## บอก AI ให้ติวแบบนี้ (วางท่อนนี้ได้เลย)

> "ติวฉันเรื่อง __ แบบ interactive: อธิบายทีละ 1 concept สั้นๆ + analogy → หยุดถาม 1 คำถามเช็คความเข้าใจ → รอฉันตอบก่อนค่อยไปต่อ. ฉันตอบถูก = ไปข้อถัดไป, ตอบพลาด = อธิบายใหม่คนละมุมแล้วถามซ้ำ. ห้าม lecture ยาวรวดเดียว. ทุก 3-4 จุด quiz ทวนสั้นๆ. ถ้าเรื่องไหนเป็นตัวเลข/เกณฑ์แล็บ บอกฉันว่าให้ไป verify กับตำรา."

ปรับ 1 บรรทัดตามสถานการณ์:
- **เวลาน้อย/ทวนก่อนสอบ:** เติม "ข้ามที่ฉันตอบคล่อง เน้นเฉพาะที่ฉันพลาด"
- **งงมาก/เพิ่งเริ่ม:** เติม "ซอยให้เล็กที่สุด ป.3 เข้าใจ ตัวอย่างก่อนนิยาม"
- **อยากจำแน่น:** เติม "ถามฉันก่อนทุกครั้ง อย่าเพิ่งเฉลย ให้ฉันเดาก่อน"

## จังหวะที่ทำให้ "interactive จริง" (ไม่ใช่ปลอม)

| AI ทำแบบนี้ = ปลอม | ควรเป็นแบบนี้ = จริง |
|---|---|
| เท 5 ย่อหน้าแล้วถาม "เข้าใจไหม" | 1 concept → ถามคำถามที่ **ต้องคิดตอบ** → รอ |
| ถามคำถามที่ตอบ "ครับ/เข้าใจ" ได้ | ถามให้ **ทำ/อธิบายกลับ** ("ลองบอกว่าทำไม...", "เคสนี้เลือกอะไร") |
| ไปต่อทันทีไม่ว่าตอบถูกผิด | ตอบพลาด → ถอยมาอธิบายใหม่ จน "ผ่าน" ก่อนไป |
| ความยากคงที่ทั้งบท | ปรับตามคำตอบ: คล่อง=เร่ง, ติด=ซอยย่อย |
| นิยามก่อนตัวอย่าง | **ตัวอย่าง/analogy ก่อน** แล้วค่อยสรุปเป็นหลัก |

## VERDICT — สั่งติวยังไงให้ได้ผล
- **ปรับระดับตามคำตอบ คือหัวใจ** — ไม่ใช่ความเร็วคงที่. ตอบคล่อง → ข้ามพื้นที่แน่นแล้ว; ตอบมั่ว → ซอยให้เล็กลง ไม่ใช่พูดซ้ำดังขึ้น
- **recall > re-read** — ก่อนสอบให้สั่ง "ถามฉันก่อน อย่าเพิ่งเฉลย" การดึงความจำออกมาเองจำได้แน่นกว่าอ่านผ่าน
- **"ยังไม่เข้าใจ" = คำสั่งให้ถอย ไม่ใช่ความล้มเหลว** — พิมพ์ได้ทุกเมื่อ ให้ AI อธิบายใหม่คนละ analogy แทนที่จะดันต่อ
- **ของวิชาการ/แพทย์ = pause + verify** — พอเป็นค่าตัวเลข/เกณฑ์/กลไก ให้มันบอกตรงๆ ว่า "อันนี้ควร cross-check" แทนที่จะ assert ลื่นๆ
- **เว้นช่วงทบทวน ไม่ใช่ติวรวดเดียว** — สั่ง AI quiz ทวนซ้ำแบบเว้นช่วง (วันนี้ → 3 วัน → 1 สัปดาห์) cram รอบเดียวลืมเร็ว; ของที่เคยพลาดให้ดึงกลับมา quiz บ่อยกว่าของที่คล่องแล้ว

## เลือกโหมดติวให้ตรงสถานการณ์

| สถานการณ์ | โหมดที่สั่ง | เพราะอะไร |
|---|---|---|
| เพิ่งเจอ concept ครั้งแรก | อธิบาย→ถาม→รอ ทีละจุด ช้าๆ | ฐานยังไม่มี ต้องวางทีละก้อน |
| ทวนก่อนสอบ (รู้บ้างแล้ว) | quiz ฉันก่อน เฉลยทีหลัง | recall ขุดจุดอ่อนจริงที่ยังไม่แน่น |
| งงเฉพาะจุดเดียว | teach-back: ฉันอธิบายกลับ AI ชี้จุดเพี้ยน | รู้เลยว่าเข้าใจผิดตรงไหนแน่ๆ |
| เนื้อเยอะ เวลาน้อย | ข้ามที่คล่อง เจาะที่พลาด | อย่าเสียเวลากับสิ่งที่แน่นแล้ว |
| ตอบผิดซ้ำ 2 รอบ | เปลี่ยน analogy + ถอยลงพื้นฐาน | พูดซ้ำเดิมดังขึ้นไม่ช่วย — ต้องเปลี่ยนมุม |

## ตัวอย่างจังหวะที่ถูก (ติว concept ยาก)

```
ฉัน: ติวเรื่อง sensitivity vs specificity แบบ interactive ทีละขั้น
AI:  คิดง่ายๆ — sensitivity = "test เก่งจับคนป่วยได้ครบไหม"
     เหมือนยามที่ไม่ปล่อยคนร้ายหลุดสักคน.
     ถาม: ถ้า test sensitivity สูงมาก แล้วผล "ลบ" แปลว่าอะไร?
ฉัน: แปลว่า... น่าจะไม่ป่วยจริง?
AI:  ใช่เลย — sensitivity สูง + ผลลบ = สบายใจว่าไม่ป่วย (ใช้ rule-out).
     ทีนี้ specificity ล่ะ ลองเดาว่ามันวัดอะไร?
ฉัน: ไม่แน่ใจ...
AI:  โอเค ถอยมาก่อน — specificity = "test ไม่ตกใจกับคนปกติไหม"
     เหมือนยามที่ไม่จับคนบริสุทธิ์มั่ว. ลองใหม่: ผล "บวก" จาก test
     specificity สูง แปลว่า?   ← (เปลี่ยน analogy + ถามซ้ำ ไม่ดันต่อ)
```
จุดที่ทำให้มัน interactive: **1 concept/คำถาม · รอเราตอบ · ตอบไม่ได้ = ถอย+เปลี่ยนมุม ไม่ใช่เทต่อ.**

## ปรับเข้ากับงานจริง
- **สอบใบประกอบ MT:** หัวข้อใหญ่ (Hema/Chem/Micro/Blood Bank) → ติวทีละ sub-topic
  - STOP = โจทย์ตีความผลแล็บ/เคสจริง 1 ข้อ
  - ตอบผิด → ทวน concept คนละมุม → quiz ซ้ำจน "ผ่าน" ก่อนไป sub-topic ถัดไป
- **DS/สถิติ (เช่น 229711):** 1 concept = 1 ขั้น (เช่น "เลือก t-test เมื่อไหร่")
  - STOP = โจทย์เลือก test จากสถานการณ์จริง
  - ผูก analogy ชีวิต/แล็บก่อนสูตร — รูปธรรมมาก่อนนามธรรม
- **concept ยากเดี่ยวๆ:** ขอ analogy ก่อน → ลองอธิบายกลับด้วยคำตัวเอง
  - AI ฟังแล้วชี้จุดที่ยังเพี้ยน = teach-back (รู้ทันทีว่าเข้าใจผิดตรงไหน)

## กับดัก (Anti-patterns)
- **AI lecture ยาวไม่ถาม** — เทเป็นบทความแล้วจบ; สั่ง "1 จุด 1 คำถาม หยุดรอฉัน" ทันที
- **สอนผิดอย่างมั่นใจ** — ตัวเลข/เกณฑ์/กลไกมั่วแต่พูดลื่น; **cross-check ตำรา/อาจารย์เสมอ** อย่าเชื่อความลื่น
- **ข้ามพื้นฐาน** — กระโดดไปขั้นสูงทั้งที่ฐานยังไม่แน่น; ถ้างงให้สั่งถอยลงไปเช็คพื้นก่อน
- **คำถามหลอกๆ** — ถามแบบตอบ "เข้าใจครับ" ได้โดยไม่ต้องคิด = ไม่เช็คอะไรจริง; ขอคำถามที่ต้อง "ทำ/อธิบายกลับ"
- **passive ก่อนสอบ** — อ่านสรุปที่มันเทแล้วคิดว่าจำได้; ต้อง recall เอง ถึงรู้ว่าจริงๆ ยังไม่แน่นตรงไหน
- **เร่งจบบท** — ดันต่อทั้งที่ยัง stumble เพื่อให้ "จบเร็ว"; ความเข้าใจสำคัญกว่าจำนวนหัวข้อ
- **เชื่อว่า interactive = ถูกอัตโนมัติ** — จังหวะดีขึ้น ≠ เนื้อหาถูก; ยัง verify เนื้อวิชาการเหมือนเดิม
- **ติวรวดเดียวก่อนสอบ (cram)** — ไม่เว้นช่วงทวน ลืมเร็ว; แบ่ง quiz ซ้ำหลายวัน (spaced) จำแน่นกว่า

## ช่องสำหรับผู้เชี่ยวชาญเติม
> เติมวิธีติว/จุดพลาดจริงในสายงานคุณ เช่น:
> - *"(MT) หัวข้อสอบใบประกอบที่ติวแบบถามทีละข้อแล้วเวิร์กสุด คือ... ผมสั่ง AI ว่า..."*
> - *"เรื่องที่ AI ชอบสอนผิด (ค่า/เกณฑ์) ต้อง cross-check ทุกครั้ง คือ..."*
> - *"analogy ที่ทำให้ concept ยาก (เช่น p-value/sensitivity) เข้าใจเลย คือ..."*
