# Contributions — พื้นที่ของชุมชน

ที่นี่ไว้โชว์สิ่งที่ MT คนอื่นส่งมาสมทบ — skill ใหม่, การเติม "ช่องสำหรับผู้เชี่ยวชาญเติม" ด้วยเคสจริง, หรือการแก้ที่ผ่านการรีวิว

ตอนนี้ยังว่าง — **คุณเป็นคนแรกได้** 🙌

## ส่งสมทบยังไง
- เจอข้อผิด / อยากเพิ่มกับดักจากหน้างานจริง / มี skill ใหม่ในสายคุณ → อ่าน [`CONTRIBUTING.md`](../CONTRIBUTING.md)
- ไม่อยากเปิด PR ก็ **เปิด issue** เล่าเคส/จุดที่ควรแก้ได้เลย
- skill ทุกอันมีหัวข้อ **"ช่องสำหรับผู้เชี่ยวชาญเติม"** อยู่แล้ว — เติมเคสจริงของคุณเข้าไปคือการสมทบที่มีค่าที่สุด

> หลักการ: เก็บ **judgment** (เลือกอะไรเมื่อไหร่ + กับดัก) ไม่ใช่ knowledge ดิบ · de-identify ข้อมูลคนไข้/สถาบันเสมอ

> 🛠️ **maintainer:** วิธีรับของที่ส่งเข้ามา → triage → แปลงเป็น skill ที่ขึ้นคลัง → [`INTAKE.md`](./INTAKE.md)
