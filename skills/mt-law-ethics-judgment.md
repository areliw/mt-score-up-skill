# โค้ชกฎหมาย/จรรยาบรรณวิชาชีพ MT — ขอบเขต/ความลับ/เครื่องมือแพทย์

ตัดสินใจหน้างานที่มีกฎหมาย/จรรยาบรรณกำกับ — "ทำได้ไหม + ผิดตรงไหนถึงโดน" ไม่ใช่ท่องมาตรา (= commodity ดูตัวบท)

> 🔑 **กฎ #1: "ทำเป็น ≠ ทำได้"** — สิ่งที่ตัดสินว่า MT ทำได้ไหม คือ **ประเภทหัตถการ + ขอบเขตวิชาชีพตามกฎหมาย/ระเบียบสภา** ไม่ใช่ว่าคุณเจาะเป็น/มือนิ่งแค่ไหน
> 🚫 **กับดัก #1: เจาะเลือดที่ MT ทำได้ = venous/capillary (peripheral) เท่านั้น** — **arterial (ABG)/jugular/femoral/ไขกระดูก = นอกขอบเขต แม้ทำเป็น**
> 🔎 **ขอบ (เส้นกลางๆ): อย่าตอบสุดทาง** — หัตถการเสี่ยงปานกลาง (whole-blood donor, OGTT, apheresis, skin test) **ไม่ใช่ "ห้ามเด็ดขาด" และไม่ใช่ "ต้องมีแพทย์ยืนด้วยทุกครั้ง"** — ขึ้นกับ *ชนิดหัตถการ + ระเบียบหน่วยงาน*: บางอย่าง MT อบรมแล้วทำได้ภายใต้ความรับผิดชอบแพทย์ (ไม่ต้องยืนกำกับ), บางอย่างต้องสั่งโดยแพทย์ → **เช็คระเบียบจริงเป็นรายหัตถการ ห้ามเหมารวม**
>
> วิชาชีพ MT = วิชาชีพควบคุม — **ทำแล็บถูกแต่ผิดกฎหมาย/จรรยาบรรณ ก็ถูกพักใบ/ฟ้องได้** · PDPA ดู `digital-judgment` · กฎหมายเครื่องมือแพทย์ตอนขาย IVD ดู `ivd-sales-judgment`
> ⚠️ อัตราโทษ/มาตราในนี้เป็น "กรอบให้รู้ว่ามีเรื่องนี้" — **ต้องตรวจตัวบทจริง + ปรึกษานักกฎหมาย** ก่อนใช้อ้างอิงจริง

## ใช้เมื่อ
- ไม่แน่ใจว่างานนี้ MT **ทำได้เอง / ต้องมี request / ต้องมีแพทย์ / ทำไม่ได้**
- จะเอาข้อมูลคนไข้/เคสออกจากแล็บ (demo/case study/วิจัย) → ต้องทำอะไรก่อน
- ขาย/demo เครื่องมือแพทย์-น้ำยา · จะโพสต์โซเชียลเกี่ยวกับงาน · เซ็นสัญญาจ้าง
- กังวลว่าผลแล็บผิด/พลาด **MT จะถูกฟ้อง/รับผิดไหม** + จะลดความเสี่ยงยังไง (Fork 6)
- ใคร **เป็นหัวหน้ากลุ่มงาน/หัวหน้าแล็บ** ได้บ้าง (จพง.วิทย์/แพทย์/เภสัช เป็นได้ไหมถ้ามี ทนพ. อยู่) + เส้นความรับผิดชอบวิชาชีพต่อผล (Fork 7)

## วิธีใช้
วาง skill นี้ + เล่าสถานการณ์ → AI ชี้ว่าอยู่ในขอบเขตไหน + กับดักกฎหมาย/จรรยาบรรณ (ไม่ใช่คำวินิจฉัยทางกฎหมาย)

## วิธีตัดสินใจ (AI: ทำตามนี้) — forks

### Fork 1 — ใบอนุญาตประกอบวิชาชีพ (ใบ ทนพ.)
- ต้องมีใบ + **เซ็นรับรองผลก่อนรายงานทุกครั้ง** · ใบหมด/ถูกพัก = ออกผลตามกฎหมายไม่ได้ · ต่อใบต้องเก็บหน่วยการศึกษาต่อเนื่อง (CMTE) ตามเกณฑ์
- 🚫 **เส้นห้ามข้ามที่ทำให้ถูกพักใบ/อาญาเร็วที่สุด: แก้/ปลอมผล, เซ็นรับรองแทนคนอื่น (หรือให้คนไม่มีใบเซ็นในนามเรา), แก้ค่าโดยไม่มี audit trail** — แม้ "ตั้งใจดี" (กันคนไข้ตกใจ/รีบส่งผล) ก็ผิด · แก้ผลที่ออกไปแล้วต้องทำเป็น **amended report ลงเวลา+ผู้แก้** ห้ามทับของเดิมเงียบๆ
- 💼 **แม้ย้ายสาย sales อย่าปล่อยใบหมดอายุ** — credibility กับแล็บ + บาง role (application specialist เข้าไป validation/training) ต้องใช้ + ประตูกลับสายแล็บ

### Fork 2 — ขอบเขตวิชาชีพ: ทำได้ / ต้องมีเงื่อนไข / ทำไม่ได้
- **ทำได้เอง:** เจาะเลือด **ดำ/ปลายนิ้ว (peripheral)**, swab/ป้าย, ตรวจวิเคราะห์ทุกสาขา, QC, เซ็นผล
- **ต้องมี request แพทย์:** EKG/EEG
- **ต้องมีแพทย์ดูแล/รับผิดชอบ (เงื่อนไขต่างกันตามหัตถการ — เช็คระเบียบจริง):** OGTT, skin test, apheresis · ⚠️ *เจาะเก็บ **โลหิตบริจาค (whole blood)** ปกติ MT/พยาบาลที่อบรมแล้วทำได้ภายใต้ความรับผิดชอบของแพทย์ — "ต้องมีแพทย์ยืนอยู่ด้วยทุกครั้ง" ไม่ใช่กฎตายตัว ขึ้นกับชนิดหัตถการ + ระเบียบหน่วยงาน*
- 🚫 **ทำไม่ได้:** เจาะ **arterial (ABG)** / jugular / femoral / **ไขกระดูก** / ปอด-ช่องท้อง-ไขสันหลัง, biopsy, สวนปัสสาวะ, ฉีดเข้าหลอดเลือด
- ⚠️ "เจาะเลือด" ที่ MT ทำได้ = **venous/capillary เท่านั้น** — arterial/marrow = นอกขอบเขต แม้ทำเป็น
- 🔑 **"แพทย์สั่ง ≠ ขยายขอบเขตวิชาชีพ"** — คำสั่งแพทย์บอก *ตรวจอะไร/รักษาอะไร* ไม่ได้แปลงใบ ทนพ. · ⚠️ MT **เก็บ specimen เชิงรุกได้ในขอบเขต** (เจาะ venous/capillary, swab ผิว) — ส่วนหัตถการรุกล้ำ (ใส่สายสวน/สวนปัสสาวะ, เก็บทาง rectal ทั้ง swab และ digital) **พรบ.วิชาชีพฯ ไม่ได้ระบุราย procedure → อย่าฟันธงเองทั้ง "ทำได้" และ "ทำไม่ได้"; ยึดข้อบังคับสภาเทคนิคการแพทย์ + ระเบียบหน่วยงาน + การมอบหมาย/competency** · ถ้าสรุป (ตามแหล่งทางการ) ว่านอกขอบเขต → **ไม่ทำเอง + escalate + จัดผู้มีอำนาจเก็บแทน** (อย่าปฏิเสธลอยจน specimen ค้าง) · *"ในสถานพยาบาล + มีคำสั่งแพทย์" ตอบแค่มุม พรบ.สถานพยาบาล ไม่ตอบมุมขอบเขต MT*
- 🔎 **เก็บปัสสาวะจาก "สายสวนที่คาอยู่แล้ว" (CSU):** คนละเรื่องกับการ "สวน" (= ใส่สาย, นอกขอบเขต) — เป็น grey-zone: ส่วนใหญ่ **มอบพยาบาลหน้างานเก็บตาม workflow** (เขาดูแลสาย/ถุงอยู่แล้ว + ไม่ใช่งานหลัก MT) → **ขึ้นกับข้อบังคับสภาฯ + การมอบหมาย + competency + SOP หน่วยงาน** (ไม่ใช่ข้อสรุปกฎหมายตายตัวว่า "ทำได้/ไม่ผิด") · *วิธีเก็บให้ specimen ไม่บวกลวง ดู `clinmicro-judgment`*
- 💼 ตอน demo เครื่องในแล็บลูกค้า: **อย่าลงมือเจาะ/เดินผลกับผู้ป่วยจริงแทนเจ้าหน้าที่** — demo บน QC/control ได้, touch คนไข้ = หน้าที่ ทนพ.เจ้าของแล็บ

### Fork 3 — ความลับผู้ป่วย + PDPA (stack กัน)
- **ข้อมูลสุขภาพ = ความลับ** (กฎหมายสุขภาพ) + เปิดเผยจากวิชาชีพ = ผิดอาญา + **PDPA: ข้อมูลสุขภาพ = sensitive data → โดยหลักต้อง explicit consent** — ทั้งหมด **ทับกัน ต้องทำตามทุกชั้น**
- ⚠️ **"ต้อง consent เสมอ" ไม่จริงเป๊ะ** — PDPA ม.26 มี *ข้อยกเว้น*: ทำเพื่อ **รักษาพยาบาล/เวชศาสตร์** ภายใต้ผู้ประกอบวิชาชีพ หรือ **ปกป้องชีวิต (vital interest)** ใช้ข้อมูลได้โดยไม่ต้องขอ consent → งานในแล็บเชิงรักษาปกติเข้าข้อยกเว้นนี้ · แต่ **เอาออกนอกงานรักษา (demo/วิจัย/โพสต์) = ไม่เข้าข้อยกเว้น → ต้อง consent + de-identify เสมอ**
- ก่อนเอาข้อมูล/เคสออกจากแล็บ (demo/case study/วิจัย/โพสต์): **de-identify + consent + ข้อตกลงประมวลผลข้อมูล** · โพสต์เคสโดยไม่ลบ identifier = ผิด
- informed consent: ผู้ป่วยมีสิทธิรู้ข้อมูลพอจะยินยอม/ปฏิเสธ (เว้นฉุกเฉิน)
- ⚖️ **บทบาทตาม PDPA: "ผู้ควบคุมข้อมูล (controller)" vs "ผู้ประมวลผล (processor)"?** — แล็บใน รพ. มักเป็น *หน่วยภายใต้* controller (ตัว รพ.) · คลินิกเทคนิคการแพทย์ที่รับตรงจากผู้ป่วยมัก = **controller** · reference/แล็บรับส่งต่อ อาจเป็น **processor หรือ controller อิสระ** แล้วแต่สัญญา → หน้าที่/ความรับผิดต่างกัน (controller แบกหน้าที่แจ้ง/เลือกฐานกฎหมาย/รับคำขอใช้สิทธิ์มากกว่า) · *บทบาทจริงขึ้นกับสัญญา/ใครกำหนดวัตถุประสงค์ — ยืนยันกับ DPO หน่วย*
- 🔑 **ผู้ป่วย = เจ้าของข้อมูล → เพิกถอนความยินยอมได้ทุกเมื่อ** (คิดค่าใช้จ่ายตามจริงที่เกิดขึ้นแล้วได้) — *เฉพาะการประมวลผลที่อาศัยฐาน consent; งานที่ใช้ฐานรักษาพยาบาล/หน้าที่ตามกฎหมาย ยังประมวลผลต่อได้ตามขอบเขต (โยง ม.26 ด้านบน)* · consent ≠ ถาวร
- 🔁 **คืนผลตามช่องทางที่รับสิ่งส่งตรวจมา:** รับตัวอย่าง/คำขอจาก OPD/แพทย์ → ส่งผลกลับช่องทางนั้น **ไม่ข้ามไปให้ผู้ป่วยตรง** เว้นมีข้อตกลงชัด + แจ้งผู้ป่วยแล้ว → กันทั้งความลับรั่ว + ผู้ป่วยตีความผลเองผิดโดยไม่มีแพทย์ (โยง `phi-data-handling`, `result-release-judgment`)

### Fork 4 — กฎหมายเครื่องมือแพทย์ (น้ำยา/IVD = เครื่องมือแพทย์)
- **ขายน้ำยา/ชุดตรวจ = ขายเครื่องมือแพทย์** → ต้องผ่านบริษัทที่มี **ใบอนุญาตขาย** (ขายนอกระบบ = โทษอาญา)
- ⚠️ **เคลม performance เกินจริง** (sensitivity/spec, "ดีกว่าเจ้าอื่น" ไม่มีหลักฐาน) = โฆษณาเข้าใจผิดในสาระสำคัญ = ผิด
- **product liability:** ผู้ผลิต/นำเข้า/**ขาย** รับผิดร่วมในความเสียหายจากเครื่อง/น้ำยาบกพร่อง (มีข้อยกเว้น/อายุความ) → **เก็บหลักฐาน calibration/QC/มาตรฐานไว้แก้ต่าง**
- 💼 IP clause ในสัญญาจ้าง sales อาจดูดงาน/โค้ดที่สร้างเอง → **ขอ carve-out เป็นลายลักษณ์อักษรก่อนเซ็น**

### Fork 5 — โซเชียลมีเดีย + จริยธรรม
- หลัก **"คิดก่อนโพสต์"** — ⚠️ **เจตนาดีก็ผิดได้** ถ้าระบุโรค/ตัวตนคนไข้ (เช่นโพสต์ขอบริจาคเลือดด่วน + ระบุว่าเป็นโรคอะไร = ผิดกฎหมายความลับสุขภาพ)
- ถ่ายรูปในแล็บ/รพ. + คนไข้ + โพสต์ = เสี่ยงผิดหลายฉบับ ทั้งแพ่ง-อาญา
- **จริยธรรม: "ถูกกฎหมาย ≠ ถูกจริยธรรม"** = judgment ไม่ใช่ rule · ของกำนัล/สินบนต่อแพทย์-แล็บในวงการแพทย์ = เส้นห้ามข้าม (trust ระยะยาว > ดีลเดียว)
- ⚠️ **MT เป็น influencer/รับงานรีวิวสินค้า = ใบประกอบฯ ติดมาด้วย:** รีวิว/โฆษณาชุดตรวจ-IVD-ผลิตภัณฑ์สุขภาพ ทั้งที่ถือใบ ทนพ. = สุ่มเสี่ยง — **เคลมเกินจริง/รีวิวไม่ตรงมาตรฐานวิชาชีพ อาจถูกร้องเรียน/มีโทษทางวิชาชีพถึงพักหรือเพิกถอนใบได้** (วงการสุขภาพเคยมีเคสถูกดำเนินการจากการรีวิว/โฆษณาสินค้า — เช็คประกาศสภาฯ ล่าสุด) · อาจทับซ้อนกฎโฆษณาเครื่องมือแพทย์ หรือกฎ อย. ของผลิตภัณฑ์นั้น (อาหาร/ยา/เครื่องสำอาง แล้วแต่ประเภท — ไม่ผิดอัตโนมัติทุกกรณี, ดู Fork 4) · **ก่อนรับงาน:** เคลมต้องมีหลักฐาน · ไม่อ้างวิชาชีพรับรองเกินจริง · ใส่ disclosure (#โฆษณา/ได้รับสปอนเซอร์) · เลี่ยงวินิจฉัย/สั่งการรักษารายบุคคล · ไม่แน่ใจ = ปรึกษาสภาเทคนิคการแพทย์/ทีมกฎหมายก่อนโพสต์ (โยง `content-creator-judgment`)

### Fork 6 — ความรับผิดเมื่อผลแล็บนำไปสู่ความเสียหาย: คดีผู้บริโภค + เอกสาร = เกราะ (อิงโพสต์นักกฎหมาย — verify ตัวบท)
- **MT อยู่ในห่วงโซ่ความรับผิด ไม่ใช่แค่ "หมอโดน":** ผลแล็บผิด/ปนเปื้อน/รายงานพลาด/ล่าช้า ที่นำไปสู่ความเสียหายต่อผู้ป่วย → ผู้ให้บริการ (รวมแล็บ/รพ.) อาจถูกฟ้องแพ่ง + ร้องเรียนทางวิชาชีพได้ · ⚠️ **อย่าคิดว่า "เป็น ขรก./รพ.รัฐ = รัฐคุ้มกัน ฟ้องไม่ถึงตัว"** — คดีการแพทย์ **บางประเภท** (มีแนววินิจฉัยบางกรณีรวมถึง รพ.รัฐ) อาจถูกจัดเป็น **คดีผู้บริโภค** ได้ *แต่เคส รพ.รัฐต้องดูเขตอำนาจศาล + กฎหมายละเมิดเจ้าหน้าที่เป็นรายกรณี* (อิงโพสต์นักกฎหมายในคอมมูฯ — *ตรวจ พ.ร.บ.วิธีพิจารณาคดีผู้บริโภค พ.ศ. 2551 + แนววินิจฉัยล่าสุดกับนักกฎหมาย, ห้ามอ้างเลขคดีลอยๆ*) · กรณีปฏิบัติหน้าที่ "ถึงตัว" เจ้าหน้าที่รัฐมักมาทาง **ไล่เบี้ย/วินัย/วิชาชีพ/อาญา** มากกว่าผู้ป่วยฟ้องแพ่งตรง — และไล่เบี้ยได้เฉพาะ **จงใจหรือประมาทเลินเล่ออย่างร้ายแรง** ไม่จำเป็นต้องเต็มจำนวน (ตามกฎหมายความรับผิดทางละเมิดของเจ้าหน้าที่ — verify)
- **ทำไมสำคัญกับ MT — ภาระพิสูจน์อาจหนักฝั่งผู้ให้บริการ:** ในคดีแนวผู้บริโภค ศาลอาจให้ภาระพิสูจน์ตกฝั่งผู้ให้บริการ **เฉพาะประเด็นข้อเท็จจริงเรื่องการให้บริการ/ระบบงานที่อยู่ในความรู้เห็นเฉพาะของผู้ให้บริการ** (แนว ม.29) — *ไม่ใช่กลับภาระทุกองค์ประกอบ (ความเสียหาย/ความสัมพันธ์เหตุ-ผล ยังต้องพิสูจน์ตามปกติ)* · ในประเด็นที่ตกมา ถ้าพิสูจน์ "ทำตามมาตรฐาน" ไม่ได้ = เสี่ยงถูกถือว่าประมาท → **บันทึก/หลักฐานที่ทวนสอบได้ = หลักฐานหลักในการสู้** (ไม่ใช่แค่งานเอกสารน่าเบื่อ — ไม่ได้แปลว่าเอกสารครบแล้วพ้นผิดอัตโนมัติ)
- 🔑 **สิ่งที่ MT คุมได้ = ทำงานให้ documented เสมอ:** QC/calibration/maintenance log · audit trail การแก้ผล (amended report ลงเวลา+ผู้แก้ — โยง Fork 1) · SOP + การทวนสอบ + บันทึกการรายงานค่าวิกฤต · บันทึก pre-analytical (sample integrity/การปฏิเสธสิ่งส่งตรวจ) — ของพวกนี้คือสิ่งที่ยืนยัน "ทำตามมาตรฐาน" เมื่อมีข้อพิพาท
- 🚫 **เส้นห้ามข้ามเมื่อเกิดปัญหา: อย่าแก้/ทับ/ลบบันทึกย้อนหลังเพื่อกลบ** — ทำลายเกราะตัวเอง + ผิดเองหนักขึ้น (โยง Fork 1) · จดตามจริง ตรงเวลา แม้พลาด
- 💡 **ประกันความรับผิดวิชาชีพ (professional liability/malpractice):** บางองค์กร/รพ. อาจมีกรมธรรม์ระดับองค์กร · ระดับ **บุคคล** สำหรับ MT ยังไม่ใช่ผลิตภัณฑ์ที่พบทั่วไปในไทยเท่ากลุ่มแพทย์/รพ. → **เช็คกรมธรรม์จริงว่างานเราถูกคุ้มครองใต้องค์กรแค่ไหน** + รู้ว่ามีช่องทำระดับบุคคล/ผ่านสมาคมวิชาชีพไหม (verify เงื่อนไขจริง)
- หลัก: **รู้ว่าตัวเองอยู่ในห่วงโซ่ความรับผิด → ลดเสี่ยงด้วยการทำงานในขอบเขต + documented + ไม่กลบเกลื่อน** ไม่ใช่ตื่นตระหนก (นี่คือกรอบให้รู้ ไม่ใช่คำปรึกษากฎหมาย — เคสจริงปรึกษานักกฎหมาย/สภาฯ)

### Fork 7 — ใครเป็น "หัวหน้ากลุ่มงาน/หัวหน้าแล็บ" ได้ + เส้นที่ห้ามเบลอ: บริหาร ≠ รับรองผล (de-identified — verify ระเบียบ/มาตรฐานหน่วย)
คำถามที่รุ่นน้องงงบ่อย: *"จพง.วิทย์ (หรือแพทย์/เภสัช) เป็นหัวหน้ากลุ่มงานเทคนิคการแพทย์ได้ไหม ถ้ามี ทนพ.ข้าราชการอยู่?"*
- 🔑 **"หัวหน้ากลุ่มงาน" โดยทั่วไป = การมอบหมายให้ปฏิบัติ/รักษาการหน้าที่บริหาร โดยผู้มีอำนาจตามโครงสร้างหน่วย (เช่น ผอ./คณะกรรมการบริหาร รพ. — อำนาจแต่งตั้งต่างกันตามต้นสังกัด) ตามคุณสมบัติ/ความเหมาะสม — ไม่ใช่ตำแหน่งที่ผูกขาดวิชาชีพโดยอัตโนมัติ** → ในทางปฏิบัติ **อาจมอบหมายให้ จพง.วิทย์/แพทย์/เภสัช เป็นหัวหน้าได้ หากไม่ขัดกรอบตำแหน่ง/คำสั่งแต่งตั้ง/ระเบียบ สธ.+ต้นสังกัด + มาตรฐานที่หน่วยถือใช้** ⚠️ *อย่าฟันธงทั้ง "โครงสร้างล็อกต้องเป็น MT" และ "ใครก็ได้เสมอ"; ตรวจระเบียบ/ประกาศฉบับปัจจุบันจริง*
- 🚫 **เส้นที่ห้ามเบลอ (จุดที่เป็นเรื่องวิชาชีพ/กฎหมายจริง): หัวหน้า = บทบาท*บริหาร* (คน/งบ/ประสานงาน) ≠ ความรับผิดชอบ*ทางวิชาชีพต่อผล*** — ไม่ว่าหัวหน้าจะเป็นวิชาชีพใด **การรับรอง/ออกผลที่เข้าข่าย "การประกอบวิชาชีพเทคนิคการแพทย์" ต้องอยู่ภายใต้ผู้มีใบ ทนพ. (หรือผู้มีอำนาจตามกฎหมาย/มาตรฐานของหน่วย)** (โยง Fork 1) — *งานวิเคราะห์บางส่วนเป็น delegated technical work/POCT/งานพยาธิแพทย์/research ได้ แต่จุดที่ "รับรองผลทางวิชาชีพ" คือจุดที่กฎหมายผูก* · หัวหน้าที่ไม่ใช่ MT สั่ง/ปล่อยให้คนไม่มีอำนาจตามวิชาชีพรับรอง-ออกผลแทน = **เสี่ยงผิด พ.ร.บ.วิชาชีพฯ/ข้อบังคับสภาฯ** ไม่ว่าใครเป็นหัวหน้า
- ⚠️ **แยก "หัวหน้ากลุ่มงาน" (บริหาร) กับ "ผู้รับผิดชอบทางวิชาการ/หัวหน้าห้องปฏิบัติการ" (technical/quality manager):** สองอย่างนี้ไม่จำเป็นต้องเป็นคนเดียวกัน และตำแหน่ง*หลัง*มักมีเกณฑ์คุณสมบัติทางวิชาชีพเข้มกว่า (เช็คมาตรฐาน/ระเบียบที่หน่วยถือใช้) — *การถกเรื่อง "ใครเป็นหัวหน้า" มักเผลอเอา 2 บทบาทนี้มาปนกัน*
- ⚠️ **อย่าสับ "ตำแหน่งบริหารตามโครงสร้าง (มีระดับ/เงินประจำตำแหน่ง)" กับ "ถูกมอบหมายให้รักษาการหัวหน้า":** บาง รพ. (โดยเฉพาะ รพช.) กลุ่มงาน MT อาจ**ไม่มีกรอบระดับสูง (เทียบ "ซี 8" เดิม) แบบสายพยาบาล/เภสัช** → "เป็นหัวหน้า" จึงอาจเป็นแค่ภาระงาน ไม่ได้มาพร้อมระดับ/เงินตำแหน่งเสมอ *(กรอบระดับเปลี่ยนตามโครงสร้าง/หน่วย — verify บัญชีอัตราปัจจุบัน)*
- 🔎 **เช็คก่อนสรุป (อย่าตอบสุดทาง):** มาตรฐานวิชาชีพ/accreditation (เช่นมาตรฐานงานเทคนิคการแพทย์/LA) ระบุเรื่อง**ผู้รับผิดชอบทางวิชาการของห้องแล็บ** ไว้แค่ไหน ต้องเปิด*ฉบับที่หน่วยใช้จริง* (รพ.ที่ไม่ได้ขอรับรองมาตรฐานนั้นอาจไม่ผูกพันในฐานะ*เงื่อนไข accreditation* — **แต่ยังถูกใช้เป็น policy/ผ่าน HA/สัญญา หรืออ้างเป็นมาตรฐานการดูแลได้**) → คำตอบ "ได้/ไม่ได้" ขึ้นกับ (ก) ระเบียบ สธ. (ข) มาตรฐานที่ขอรับรอง (ค) ดุลพินิจผู้บริหาร — ไม่ใช่กฎข้อเดียวทั่วประเทศ
- 💡 **มุมตัดสินใจ (รุ่นน้องที่กังวลตำแหน่ง):** ผอ.มักแต่งตั้งคนที่สนองคุณภาพ รพ.ได้ + ธรรมเนียมอาวุโสยังมีน้ำหนักจริง → เร่ง "ตำแหน่ง" ตรงๆ มักไม่ได้ผลเท่า **ทำให้ขาดเราไม่ได้ (competency/QC/ทำงานข้ามวิชาชีพ)** แล้วตำแหน่งตามมา · "เป็นหัวหน้า" ไม่ได้ดีเสมอ — รับผิดชอบ↑ บางโครงสร้างเงินเท่าเดิม · ladder/เพดานระดับ → `mt-career-judgment` · งานบริหารแล็บจริง (QMS/accreditation/ผู้รับผิดชอบวิชาการ) → `lab-management-judgment`

## กับดัก (Anti-patterns)
- 🚫 **เจาะ arterial/jugular/femoral/ไขกระดูก** — นอกขอบเขต MT (peripheral venous/capillary เท่านั้น)
- 🚫 **ทำหัตถการเสี่ยง (apheresis/OGTT/skin test) โดยไม่มีแพทย์ดูแลตามระเบียบ** — เช็คเงื่อนไขแต่ละหัตถการ (เจาะ whole-blood donor ปกติทำได้ภายใต้ความรับผิดชอบแพทย์)
- 🚫 **โพสต์เคส/รูปคนไข้ แม้เจตนาดี** — ระบุโรค/ตัวตน = ผิดความลับสุขภาพ + PDPA
- 🚫 **เอาข้อมูลคนไข้ออกจากแล็บโดยไม่ de-identify/consent** — ม.ความลับ + PDPA sensitive data
- 🚫 **เคลม performance เกินจริงตอนขาย** — โฆษณาเข้าใจผิด ผิดกฎหมายเครื่องมือแพทย์
- 🚫 **ปล่อยใบ ทนพ. หมดอายุ** ตอนย้ายสาย — เสีย credibility + ประตูกลับ
- 🚫 **เซ็นสัญญา sales โดยไม่อ่าน IP/ข้อผูกมัด** — งานที่สร้างเองอาจถูกดูด
- 🚫 **แก้/ปลอมผล หรือเซ็นรับรองแทนคนอื่น** — เส้นห้ามข้ามขั้นพักใบ/อาญา แม้เจตนาดี; แก้ผลที่ออกไปแล้ว = amended report ลงเวลา ห้ามทับเงียบ
- 🚫 **เชื่อว่า "แพทย์สั่ง = ทำได้ทุกอย่าง"** — คำสั่งแพทย์ไม่ขยายขอบเขต ทนพ. ให้ทำหัตถการที่ระเบียบไม่ครอบ (ใส่สายสวน/สวนปัสสาวะ/เก็บ rectal เชิงรุก) · ถ้านอกขอบเขต = **ไม่ทำเอง + escalate + จัดผู้มีอำนาจเก็บแทน** (ไม่ใช่ปฏิเสธลอยจน specimen ค้าง) — *MT เจาะ venous/capillary เชิงรุกได้ในขอบเขต อย่าเหมารวมว่าห้ามเก็บเชิงรุกทุกอย่าง*
- 🚫 **คิดว่า "เป็น ขรก./รพ.รัฐ ฟ้องไม่ถึงตัว MT"** — คดีการแพทย์ (รวม รพ.รัฐ) ดำเนินแบบคดีผู้บริโภคได้ + หน่วยไล่เบี้ยประมาทร้ายแรงได้; เกราะจริงคือ **บันทึก/QC/audit trail ที่ทวนสอบได้** ไม่ใช่สถานะราชการ (Fork 6 — verify ตัวบทกับนักกฎหมาย)
- 🚫 **ทำงานไม่ documented / แก้บันทึกย้อนหลังกลบปัญหา** — ภาระพิสูจน์ "ทำตามมาตรฐาน" มักตกฝั่งผู้ให้บริการ; ไม่มีหลักฐาน = เสี่ยงถูกถือว่าประมาท + การกลบ = ผิดเอง (Fork 6)
- 🚫 **คืนผลข้ามช่องทาง / ถือ consent เป็นถาวร / สับบทบาท controller-processor** — ส่งผลตรงให้ผู้ป่วยทั้งที่รับงานผ่าน OPD โดยไม่มีข้อตกลง · ลืมว่าผู้ป่วยเพิกถอน consent ได้ · เหมาว่าแล็บ รพ. เป็น controller ทั้งที่มักเป็น processor (Fork 3)
- 🚫 **เหมาว่า "ตามโครงสร้าง สธ. หัวหน้ากลุ่มงาน MT ต้องเป็น ทนพ. เสมอ" (หรือสุดทางว่า "ใครก็ได้")** — โดยทั่วไปเป็นการมอบหมายโดยผู้บริหาร (กบบ.+ผอ.) ตามคุณสมบัติ จพง./แพทย์/เภสัช เป็นได้ *(verify ระเบียบ/มาตรฐานหน่วย)* · **แต่เส้นห้ามเบลอ: การรับรอง/ออกผลที่เข้าข่ายประกอบวิชาชีพฯ ต้องอยู่ภายใต้ผู้มีใบ ทนพ./ผู้มีอำนาจตามกฎหมาย ไม่ว่าหัวหน้าเป็นวิชาชีพไหน** (Fork 7)

> - *"(MT) เคสที่เกือบทำนอกขอบเขต/เกือบโพสต์ผิด จับได้เพราะ..."*
> - *"ตอนเซ็นสัญญา/ขายของ จุดกฎหมายที่ผมเจอจริง คือ..."*

---
*ช่วยเข้าใจกรอบกฎหมาย/จรรยาบรรณวิชาชีพ MT เพื่อการศึกษา ไม่ใช่คำปรึกษาทางกฎหมาย — ตัวบท/อัตราโทษต้องตรวจฉบับล่าสุด + ปรึกษานักกฎหมาย/สภาวิชาชีพก่อนตัดสินใจจริง · ผู้นำไปใช้รับผิดชอบการตัดสินใจที่นำไปใช้จริง · ผู้สร้างไม่รับผิดต่อความเสียหายจากการนำไปใช้*
